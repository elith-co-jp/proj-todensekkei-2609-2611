# 画面の文言とアイコンの決まり

画面のボタン・見出し・説明の書き方をそろえるための決まりです。AutoCAD・KiCad・EPLAN などの CAD ツールと、
PLC の設定ツールの書き方を参考にしています。新しい画面やボタンを足すときは、この表の言葉とアイコンを使ってください。

## 1. 書き方

| 決まり | 例 |
|---|---|
| コマンドは名詞か「名詞＋動作」の短い語にする。目安は 2〜6 文字 | 「回路を組んでシミュレーションする」→「回路を作成」 |
| 文にしない。「〜する」「〜したら」で終えない | 「動作させたら」→「強制 ON」 |
| 対象の数は括弧で後ろに付ける | 「選択 3 件の回路を確かめる」→「回路検証（3 件）」 |
| 説明はパネルの上に 1 行だけ。くわしい説明はボタンや見出しのツールチップ（title）に入れる | 「入力の ON / OFF を時刻順に並べ、タイマーを含めて実行する。」 |
| ツールチップには、短い説明とショートカットを書く | 「全体表示（F／ダブルクリック）」 |
| 設計者が普段使う言葉を使う（励磁、通電、a 接点・b 接点、強制 ON / OFF、シート間接続、ネットリスト） | 「電圧あり」→「通電」 |
| 同じことは画面が違っても同じ言葉にする | 書き出す操作はすべて「書き出し」／「〜出力」 |

## 2. 用語

| 使う言葉 | 使わない言葉 | 意味 |
|---|---|---|
| 図面一覧 | 図面ワークスペース | 図面の登録・一覧の画面 |
| 回路検証 | 回路シミュレーション、回路の確認・もしも | 回路を作って動作・波及を確かめる画面 |
| 入出力 | データ受け渡し | ZIP の書き出し・読み込みの画面 |
| AI 学習 | AI 改善サイクル（画面名として） | 推論・学習・モデル管理の画面 |
| ヘルプ | 操作ガイド | 手順とショートカットの画面 |
| 回路を作成／再作成 | 回路を組んでシミュレーションする／組み直す | アノテーションから回路を作る |
| 図面選択 | 図面を選ぶ／選び直す | 対象の図面を選ぶ |
| 全選択／選択解除 | すべて選ぶ／選択を外す | |
| 警告 n | 回路にできなかった箇所 n 件（見出しでは使う） | 回路にできなかった箇所の件数 |
| 操作・機器・条件・波及・タイマー・検査・変更 | 動かす・器具一覧・図面を読む手順・もしも・波及・時間の流れ・点検・図面の変更 | 回路検証のパネルのタブ |
| 機器／電線番号／要確認 | 器具一覧／線番／警告 | 機器タブの一覧の種類（DD-0044）。「要確認」は判定ではなく見るべき箇所 |
| リレー／外部入力／負荷 | コイルあり／入力接点／出力 | 機器タブの器具の種類 |
| 強制 ON／強制 OFF | 動作させたら／動かなくなったら | 機器を今の状態から強制的に動作・非動作にしたときの変化 |
| 全 OFF | すべて OFF に戻す | 入力をすべて OFF にする |
| 実行 | 時間の順に解く | タイマーの並びを実行する |
| 行を追加／行を削除 | 操作を足す／操作を消す | |
| チェック実行／再チェック／一括修正／修正を適用 | 矛盾をチェック／もう一度チェック／矛盾をまとめて直す／この直し方を適用 | 整合性チェック |
| 逆引き／順引き、成立／不成立／判定不能 | 条件を調べる／影響を調べる、OK／NG／不明 | 条件タブ（図面を読む手順） |
| 試行／適用／元に戻す | 試す／取り消す | 図面の変更 |
| 通電／接点 閉／接点 開／励磁 | 電圧あり／閉じた接点／開いた接点／励磁したコイル | 図面に重ねる凡例 |
| 図面セット | 図面グループ、図面の組 | 行先札でつながる一続きの図面の組（DD-0041） |
| シート間接続 | 図面間のつながり | 行先札・来先札で図面をまたいだ接続 |
| 書き出し、〜出力 | 出力する、を出力 | ファイルを書き出す |
| AI 取込 | AI 推論（エディタのボタン） | 保存済みの AI の結果を候補として取り込む |
| 選択・シンボル・端子・配線 | 選択・移動／シンボル描画／端子を置く／配線 (from-to) | エディタのモード |
| 全体表示／全画面 | 全体／図面を全画面で見る | |

## 3. アイコン（lucide-react）

| 用途 | アイコン |
|---|---|
| 図面一覧 | `FileStack` |
| 回路検証・回路を作成 | `CircuitBoard` |
| 入出力 | `ArrowDownUp` |
| AI 学習 | `BrainCircuit` |
| ヘルプ | `CircleHelp` |
| ツアー | `Compass` |
| 図面選択 | `Files` |
| 図面セット | `Layers` |
| 選択をセットとして保存／今の選択でセットを更新 | `FolderPlus`／`Save` |
| 行先札から候補 | `Sparkles` |
| 再作成 | `RefreshCw` |
| 操作（入力の切り替え） | `ToggleRight` |
| 機器（機器索引） | `Tags` |
| 条件（逆引き・順引き） | `Route` |
| 波及 | `Network` |
| タイマー | `Timer` |
| 検査 | `ShieldCheck` |
| 変更 | `PenLine` |
| 強制 ON／強制 OFF／全 OFF | `Power`／`PowerOff`／`PowerOff` |
| 実行 | `Play` |
| 全体表示 | `Scan` |
| 全画面／全画面を終了 | `Maximize`／`Minimize` |
| パネルを開く／閉じる | `PanelRightOpen`／`PanelRightClose` |
| 書き出し | `Download` |
| コード出力 | `FileCode2` |
| 対応表（Excel） | `FileSpreadsheet` |

## 4. ショートカット（回路検証）

| キー | 動作 |
|---|---|
| F | 全体表示 |
| ＋／− | 拡大／縮小 |
| P | パネルを開く／閉じる |
| Esc | 全画面を終了 |
