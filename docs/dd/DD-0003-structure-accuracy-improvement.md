# DD-0003: 構造解析精度の改善（シンボル検出再学習＋配線グラフ組立強化）

- 状態: レビュー中
- 作成日: 2026-10-12
- 関連文書: [SPECIFICATION.md](../SPECIFICATION.md)

## 1. 背景

ユーザーの実図面アノテーション（seq-annotator エクスポート 2 ZIP・計30ページ）を正解データとして現行パイプラインを評価したところ、シンボル検出 F1 0.73（IoU≥0.5）、接続ペア F1 0.36 だった。主因は2点:

1. 同梱モデルが旧8クラス体系（`yolo11n_all_symbols_best.pt`）で、現行12クラス体系と不一致。
2. 配線グラフの組立が保守的すぎ、ワイヤ検出自体はほぼ完全でもネットが細かく分断される（接続ペア再現率 0.24）。

## 2. 目的

- シンボル検出: 現行12クラス体系で再学習し、実図面での検出精度を引き上げる。
- 配線検出: 同じワイヤ検出結果から、より完全な接続グラフを組み立てる。
- 目標はユーザー要求どおり最低 98% だが、評価基盤上で可能な限り高い値を取り、限界要因を明確化する。

## 3. スコープ

- 対象: `analysis/tools/run_yolo_e2e_pipeline.py`、`analysis/tools/filter_wire_decorations.py`、`analysis/runtime.py`、学習済み重みの差し替え。
- スコープ外: アノテーションエディタUI、フロントエンド、学習機能の外部実行モード（変更不要）。

## 4. 変更案の概要

### 4.1 シンボル検出モデル

- 添付アノテーションZIPの `dataset/images|labels`（YOLO形式・12クラス一致）をそのまま学習データとして利用（train 24 ページ / val 6 ページ）。
- yolo11n・imgsz 1280・図面に無害な増強のみ（mosaic/translate/scale/copy_paste/erasing。反転・回転・HSVは図面意味を壊すため無効）。
- 稀クラス（contact_b・solenoid・power_bus、計31個体）が未検出になるため、ゴールド切り抜きを学習ページへ合成した増補データ（+96枚）でファインチューニング。

### 4.2 配線グラフ組立

1. **シンボル内部導通ブリッジ**: `symbol_terminal_bridge_classes` に `contact_a, contact_b, solenoid, relay_coil, lamp, push_button, diode, junction` を指定。2端子素子の P1-P2 を同一ノードに併合する（ラダー図の直列素子）。connector/terminal はピンごと別ノードのため除く。
2. **全クラスのポート推定**: `DEFAULT_INFERRED_TERMINAL_CLASSES` を全12クラスへ拡張。bbox辺上の実インク接触点をポートとして使うため、端子アノテーション無しでも connector/other 等が接続できる。
3. **接線フォールバック**: `TOUCHING_WIRE_FALLBACK_CLASSES = {connector, junction, power_bus, terminal}`。端子リンクが無いとき bbox に接するワイヤへ接続する。
4. **ジャンクション導通**: `junction_node_policy` を `all` に。ワイヤグラフのジャンクションノードは実インク交点のみに生成されるため、全て導通としてよい。
5. **破線保持**: `filter_wire_decorations` で 400px 未満の破線セグメントを保持（`DASHED_RULE_MIN_LENGTH`）。短い破線はシーケンス図の機械的/電気的連結であり、正解データでも接続として数えられていた。長い罫線・罫は従来どおり除去。
6. **ギャップブリッジ緩和**: `DIRECT_*` 閾値を TERMINAL_GAP 160 / WIRE_GAP 80 / TERM-TERM 140 / NODE_ANCHOR 24 に拡大（alignment・文字・シンボル重なりチェックは維持）。

## 5. 評価方法

- `work/driver.py`（セッション作業ディレクトリ）: 添付PNGに対し `analyze_image` + `process_page` を実行し `evaluate_inferred_graph` で採点。
- 指標: シンボル IoU閾値別 P/R/F1（0.3/0.5/0.7）、接続ペア P/R/F1（netクリーク、from_toエッジ由来のクリーク）、配線辺再現率（ゴールド各ワイヤ辺の両端が同一予測成分に入る割合）。
- ベースライン: 旧8クラス重み＋旧パラメタ。

## 6. 結果

正解30ページでの最終測定（新モデル: yolo11n・imgsz 1280・conf 0.45、conf 掃引で最適を選択）:

| 指標 | ベースライン | 改善後 |
| --- | --- | --- |
| シンボル F1 (IoU≥0.3) | 0.76 | 0.962 |
| シンボル F1 (IoU≥0.5) | 0.73 | 0.947 |
| シンボル F1 (IoU≥0.7) | — | 0.83 |
| 接続ペア F1（from_to クリーク） | 0.36 | 0.73 |
| グラフペア F1（nets クリーク） | 0.36 | 0.64 |

- ゴールドシンボル与件での配線側上限: 接続ペア F1 ≈0.79。残る FN はワイヤ再構成自体の検出欠損、残る FP は隣接並列線への誤接続が主因。
- 稀クラス合成増強（96枚）ファインチューニングは実評価で悪化したため不採用（切り抜き貼り付けが実図面分布と乖離）。採用モデルは元データ30ページのみ学習のもの。
- conf を下げると recall は伸びるが precision 低下が上回るため 0.45 付近が最適。

## 7. 残課題・判断事項

- 98% は厳格なペアクリーク指標では未達の見込み。どの指標を「精度98%」の公式定義とするかユーザー確認が必要（辺再現率ならより高い値になる）。
- `junction_node_policy='all'` は実インク交点のみを導通させるため、ドット無し交差を非導通とする図面流儀がある場合は `explicit` への戻しを検討。
- 破線＝接続の扱いは現データの慣例に依存。破線を非接続とする図面では `DASHED_RULE_MIN_LENGTH` を下げるか従来動作へ。
