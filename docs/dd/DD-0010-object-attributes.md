# DD-0010: 記号・配線の属性と、オブジェクト ID と 1 対 1 の JSON

- 状態: レビュー中
- 作成日: 2026-11-07
- 関連文書: [DD-0009-circuit-simulation.md](DD-0009-circuit-simulation.md), [DATA_FORMAT.md](../DATA_FORMAT.md) §6, [SPECIFICATION.md](../SPECIFICATION.md)

## 1. 背景と目的

回路の情報だけでなく、記号と配線の 1 つ 1 つにメーカー・型式・長さなどの属性を持たせ、オブジェクトと 1 対 1 で管理できる JSON を生成・管理したい（2026-11-07 のご要望）。

## 2. 変更内容

| 対象 | 変更 |
| --- | --- |
| DB | `annotation_symbols.attributes_json`、`connections.ref`・`connections.attributes_json` を追加。既存の DB には起動時に列を足す |
| 配線の参照名 | 配線は保存のたびに作り直されるため、固有の名前が無かった。W-0001 形式の参照名を付け、指定があれば保ち、無いか重複していれば空き番号を振る。エディタも配線を作るとき・AI の配線を取り込むときに同じ規則で振る |
| 保存・読み込み | `PUT /api/projects/{id}/annotations` の `symbols[].attributes`・`connections[].ref`・`connections[].attributes`。空の値は保存しない。属性は 100 個まで、名前は 64 文字まで、文字の値は 1000 文字まで |
| エディタ | 記号と配線の詳細に「属性」欄。標準の項目（記号の種類・配線で変わる）と、自由に足した項目を編集する。エディタは保存のたびに全体を送るので、属性と参照名も送り返す（送らないと保存のたびに消える） |
| 属性の JSON | データ受け渡しの画面で、全オブジェクトをオブジェクト ID と 1 対 1 で並べた JSON を書き出す（値のみ / 入力用の空欄つき）。編集した JSON を取り込むと、載っているオブジェクトの属性を置き換え、重複・見つからない・種類違い・数値でない値を報告する。形式は DATA_FORMAT.md §6 |
| ZIP | bundle.json に属性と配線の参照名が入り、取り込みで復元する |
| 回路シミュレーション | コイル・電磁弁の `coil_resistance_ohm` があれば負荷の抵抗に使う（無ければ 1 kΩ） |

属性の項目は固定のマスタにせず、標準の項目の定義（`services/attribute_definitions.py`）と自由な項目の組み合わせにした。図面の種類やお客様ごとに要る項目が変わるため。

## 3. 検証

| 確認内容 | 方法 | 結果 |
| --- | --- | --- |
| 保存し直し | 属性つきで保存し、読み込んだ内容を配線の順を変えて保存し直す | 配線の参照名と属性は同じ配線に付いたまま。空の値は保存されない |
| 入力の検査 | 長すぎる項目名、配列の値 | 422 |
| JSON の書き出し | 記号 2・配線 2 の図面 | 4 件が 1 件ずつ、オブジェクト ID 順に並ぶ。入力用は種類別の項目を null で並べる |
| JSON の取り込み | 値の変更、null、「3,000」、数値でない値、重複、存在しない ID、種類違い、2 回目の取り込み、図面 ID が違う環境 | すべて期待どおり報告・反映。2 回目は更新 0 件。シート番号で照合 |
| ZIP の往復・既存 DB・回路 | ZIP を書き出して取り込む、列の無い DB を起動、コイル抵抗つきで回路を組む | 属性と参照名が復元。列が足される。ネットリストの負荷が 4400 Ω |
| 画面 | エディタで記号のメーカー・コイル抵抗、配線の長さ・電線種別を入力し、自動保存後に API で確認。データ受け渡しの画面で入力用を書き出し、配線の色を足して取り込む（合成の図面） | 保存・書き出し・取り込みとも反映。画面は docs/screenshots/editor-attributes-wire.png、export-object-attributes.png |

## 4. 残課題

- 端子・図面そのものの属性は対象外。
- 配線の長さは図面からは読めないため、入力するか JSON で取り込む。配線の抵抗を回路シミュレーションに入れることは未対応（DD-0009 は配線を導線として扱う）。
- 属性の項目の標準は暫定。お客様が管理したい項目に合わせて定義を足す。
