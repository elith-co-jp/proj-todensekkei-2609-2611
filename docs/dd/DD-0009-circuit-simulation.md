# DD-0009: 図面のアノテーションからの回路シミュレーション（On/Off の動作確認）

- 状態: レビュー中
- 作成日: 2026-11-07
- 関連文書: [DD-0007-accuracy-improvement-real-drawings.md](DD-0007-accuracy-improvement-real-drawings.md), [SPECIFICATION.md](../SPECIFICATION.md), [DATA_FORMAT.md](../DATA_FORMAT.md)

## 1. 背景と目的

図面を回路に変換し、接点の On/Off で電気がどこまで通り、どのリレーが動くかを確かめたい（2026-11-07 のご要望）。
入力は、AI の取り込みと人の修正で確定したエディタのアノテーション（記号・端子・配線・ラベル）とする。AI の構造解析の結果をそのまま使うと、配線の見落とし（つながりの再現率 0.922、DD-0007 §4.22）がそのまま回路の誤りになるため。

## 2. スコープ

- 対象: 選んだ 1 枚以上の図面。母線（PER…/NER…）と、器具番号が同じリレーは図面をまたいでつなぐ。
- 対象外: 時間の経過（コイルの動作時間・タイマー）、電流値・電圧降下の評価、コネクタの端子名による図面間の接続。

## 3. 回路の組み方（`services/circuit_model.py`）

| 図面の要素 | 回路 |
| --- | --- |
| 配線でつながった端子 | 1 つのノード。コネクタ・分岐点・端子・母線端は通り抜けの点で、全端子を同じノードにする |
| 接点・コイルの両端を結ぶ線 | 導線にしない。エディタでは接点の両端を線で結んで接点を表すため（人の登録も同じ） |
| 母線 | 母線端の位置に最も近い PER/NER の文字で決める。PER2100100 → P_2100100、NER → 0（負側は共通の基準）。母線の名前ごとに直流 110 V の電源を置く。母線端が無ければ、PER/NER の文字の下に並ぶ分岐点を母線とみなし、推定したことを診断に出す |
| a 接点・b 接点 | 開閉する接点。器具番号と機器名（「33HB FV2306」、括弧の参照先シートは除く）が同じコイルで開閉する。機器名の無いラベル（「33LA」）は、器具番号が同じコイルが 1 つだけならそのコイル |
| コイルの無い接点 | 外部入力。利用者が On/Off を決める |
| リレーコイル・電磁弁・表示灯・ダイオード | 負荷の抵抗（1 kΩ） |

端子が 2 個でない接点・コイル、PER と NER が導線でつながっているもの、接点の無いコイル、器具番号の無い接点などは「確認が必要な箇所」として返す。アノテーションを直すとシミュレーションに反映される。

## 4. シミュレーション

接点の開閉を決めると回路は抵抗と直流電源だけになるので、各ノードの電圧を SPICE の動作点解析（`.op`）で求める。コイルの両端の電圧が電源の 7 割以上なら励磁とし、接点を開閉し直して、状態が変わらなくなるまで繰り返す（上限 30 回。同じ状態に戻れば発振として警告）。
前の励磁状態から始めるので、押しボタンを離しても自己保持の回路は保持され、停止ボタン（b 接点）で切れる。電源の電流が 10 A を超えれば短絡として警告する。

ngspice があればそれで解き（`SEQANNO_NGSPICE` または PATH）、無ければ同じネットリストを内蔵の節点解析で解く。Windows 版の EXE には ngspice を同梱していないので内蔵の解き方になる。両方の結果が同じことをテストで確かめた。

ネットリストの書き出し（`.cir`）は LTspice・ngspice でそのまま開ける形にする。接点はコイルの電圧で開閉するスイッチ（`SW`）、外部入力は `.param` で、値を 0/1 に変えて `.op` で解く。

## 5. API と画面

- `POST /api/circuit/build` `{project_ids}`: コイルとその接点、外部入力、確認が必要な箇所、電源、解き方。
- `POST /api/circuit/simulate` `{project_ids, inputs, energized}`: コイルの励磁と電圧、図面ごとの配線（電圧あり）・接点（開閉）・コイル（励磁）の重ね表示用の座標。
- `POST /api/circuit/netlist` `{project_ids, inputs}`: ネットリストのファイル。
- 画面「回路シミュレーション」（`/circuit`）: 図面を選んで回路を組み、外部入力を切り替えるたびに前の状態から解く。図面の上に、電圧のかかった配線を赤、閉じた接点を緑の枠、励磁したコイルを赤で重ねる。

## 6. 検証

| 確認内容 | 方法 | 結果 |
| --- | --- | --- |
| 自己保持の回路 | 押しボタン・停止ボタン・コイル X・保持接点・表示灯の回路を作り、押す → 離す → 停止 の順に解く（ngspice と内蔵の両方） | 押すと励磁し表示灯に 110 V、離しても保持、停止で切れる |
| 図面をまたぐ回路 | 同じ回路の図面 2 枚で、母線の名前と同じ器具番号のコイルがつながること | 1 つの電源・1 つのリレーになる |
| 診断・短絡 | 端子の足りないコイル、PER と NER の導線、電源をまたぐ閉じた接点 | それぞれ診断・警告になる |
| API | 保存したアノテーションから組み立て・シミュレーション・ネットリスト。書き出したネットリストを ngspice で解く | 期待どおり。ngspice でも押しボタン On でコイルの制御が 1、表示灯 110 V |
| 実図面 | 未学習ページ u007 を登録し、AI の取り込み結果をアノテーションとして保存して画面で操作 | 2 系統の電源（P_2100100・P_2100120）、リレー 3、外部入力 3。器具番号の無い接点を On にするとコイル 30R が励磁し、母線から 30R までの配線が赤くなる。33HB のコイルが母線に直結している取り込みの誤りは常に励磁として現れる |

## 7. 残課題・判断事項

- 正解データ（人の登録 30 枚）はリレーコイルに端子と配線を付けていない（DD-0007 §6）。シミュレーションにはコイルの配線が要るので、登録の取り決めにコイルの配線を加えるかを決める。
- コネクタの端子名による図面間の接続、行先・来先の記号による母線以外の接続は未対応。
- 励磁の判定（電源の 7 割）と負荷の抵抗（1 kΩ）は On/Off を見るための仮の値。電圧・電流の値は評価に使わない。
- ngspice を EXE に同梱するか（BSD ライセンス）。
