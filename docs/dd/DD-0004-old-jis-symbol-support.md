# DD-0004: 旧JIS（JIS C 0301 系列2）図記号への対応

- 状態: レビュー中
- 作成日: 2026-10-12
- 関連文書: [DD-0003-structure-accuracy-improvement.md](DD-0003-structure-accuracy-improvement.md), [SPECIFICATION.md](../SPECIFICATION.md)

## 1. 背景

ユーザーから「旧JISにも対応できるようにしてほしい」との要求。現行モデル（DD-0003 で再学習した12クラス yolo11n）は新JIS（JIS C 0617＝IEC方式）字形で学習しており、旧JIS（JIS C 0301 系列2）で描かれた図面では検出できない。

実際に旧JIS形式のシーケンス図（JEM-TR 222 相当の参考回路図）を現行モデルへ入力したところ、接点はすべて `connector` に誤分類され、`contact_a`/`contact_b`/`lamp` 等は一切検出されなかった。旧JIS評価セット（後述）での測定値はシンボル F1 0.71（IoU≥0.5）と、新JIS評価の 0.947 を大きく下回る。

## 2. 目的

- 旧JIS字形のシンボルを、対応する現行クラス（contact_a / contact_b / lamp / push_button 等）として検出できるようにする。
- 新JIS図面での精度（F1 0.947 @IoU0.5）を維持する（回帰防止）。
- 配線検出は新旧で共通のため、主な対象はシンボル検出モデルとする。

## 3. スコープ

- 対象: 学習済み重み `analysis/weights/yolo11n_all_symbols_best.pt` および `assets/models/yolo11n_all_symbols_best.pt` の差し替え（両方）。学習手順の文書化。
- スコープ外: パイプラインコード、エディタUI、フロントエンド。旧JIS実図面での公式評価（実アノテーションデータが無いため）。

## 4. 変更案の概要

### 4.1 旧JIS字形の差分（JIS C 0301 系列2 → 対象クラス）

- `contact_a`/`contact_b`: 両端に開放円（○）＋斜め開放刃（a）/閉合刃＋断路バー（b）。新JISの刃のみ表記と大きく異なり、現行モデルは円を `connector` と誤認する。
- `lamp`: 新JISは ⊗（円＋X）、旧JISは 円＋放射状の光線。
- `push_button`: 接点形＋押ボタンバー。
- `relay_coil`/`solenoid`: 本図面規約ではすでに円形（旧JISと同系）のため差替不要と判断。
- `terminal`/`junction`/`connector`/`power_bus`/`diode`/`other`: 新旧で形状差が小さい、または対象外。

### 4.2 学習データ生成（実図面への字形差替）

実図面の背景・配線・タグ文字を保持したまま、ゴールドbbox内の新JIS字形だけを旧JIS字形へ描き替える方式（前回の切り抜き合成が実評価で悪化した経験を反映し、分布乖離を最小化）。

- 学習スクリプト: `work/oldjis.py`（セッション作業ディレクトリ）。bbox内のレール列（垂直ワイヤが貫通する列）を検出し、その±14pxバンドを白抜きして旧JIS字形を描画。
- `contact_a`/`contact_b`/`push_button`: 確率0.85で差替（残りは新JISのまま混在）。
- 差替する `contact_a` の一部を希少クラスへ再割当（旧JIS形を教えることが目的のため、描き替え後の形状に合わせてラベルも変更する）: 55% `contact_a` / 25% `contact_b` / 10% `push_button` / 5% `diode` / 5% `lamp`。接点bboxはレール上の清浄な字形スロットが保証されるため、実データ0〜極少クラスの実例を量産できる。
- `other` のうちレール貫通かつ描画位置が清浄なもの: 確率0.5で稀クラスへ描き替え＋ラベル変更。**注意点**: bbox全体をラベルに使うと、表題欄などの巨大blob内に微小字形を描いた不正ラベルが生成され学習を壊す（初回学習で lamp/PB/diode の recall が0だった原因）。字形サイズのスライスだけを描画・ラベル対象とし、描画帯域のインク量を事前チェックして上書きを避ける。
- 学習セット: 元ページ24枚＋差替版24枚（`_oj` サフィックス）。val は元6枚＋差替版4枚（EarlyStoppingのfitnessが旧JISを見るように必須——初回はvalが新JISのみで1epoch打ち切りになった）。

### 4.3 学習

- 現行 `runs/y11n_1280_full/weights/best.pt` からファインチューニング（yolo11n・imgsz 1280・lr0 0.0015・cos_lr・close_mosaic=15・120epoch・batch 8・CPU・patience=0）。

## 5. 評価方法

- 旧JIS評価セット: val 6ページの適格シンボル全件を旧JIS字形へ差替（`oj_eval`、レイアウトは学習未使用）→ YOLO単体で class-aware IoU マッチ採点（P/R/F1、per-class）。
- 回帰評価: `work/driver.py predict` で正解30ページ（新JIS）のフルパイプライン採点。
- 外部実例: 公開されている旧JIS回路図への推論（定性確認）。

## 6. 結果

採用モデル: `runs/detect/runs/y11n_oj3/weights/best.pt`（120epoch、best=108epoch目、val mAP50 0.477）。

### 6.1 旧JIS評価（oj_eval: val 6ページの適格字形を全件旧JIS化、学習未使用レイアウト）

conf=0.50・IoU≥0.5・class-aware マッチ:

| 指標 | 現行モデル | 旧JIS対応モデル |
| --- | --- | --- |
| シンボル F1 | 0.707 | **0.871** |
| Precision | — | 0.893 |
| Recall | — | 0.850 |

per-class recall（旧モデル → 新モデル）: contact_a 0.17→0.79、contact_b 0→0.43、junction 0.58→0.94、connector 0.74→0.92、relay_coil →1.00。push_button は評価6件すべて未検出（旧JIS PB は実図面実例0件のため合成のみ、今後の課題）。

### 6.2 新JIS回帰評価（正解30ページフルパイプライン）

同一 conf=0.50 の比較:

| 指標 | DD-0003モデル | 旧JIS対応モデル |
| --- | --- | --- |
| シンボル F1 @IoU0.3 | 0.6736 | **0.9504** |
| シンボル F1 @IoU0.5 | 0.6548 | **0.9408** |
| シンボル F1 @IoU0.7 | 0.4574 | **0.8485** |
| fromto-pairs F1 | 0.3335 | **0.7188** |
| edge-recall | 0.2576 | **0.8020** |

参考（各モデルの最良 conf 付近）: DD-0003モデルは検出スコアが 0.45〜0.5 帯に集中しており conf=0.45 で F1@0.5=0.9469 が上限、conf=0.50 で大半が閾値割れする。旧JIS対応モデルは検出スコア自体が高く、conf=0.50 で F1@0.5=0.9408・conf=0.45 でも 0.9116。**同一閾値では全指標で新モデルが大幅に優れる**ため回帰ではなく改善であり、conf 0.50 運用を推奨する。

### 6.3 定性確認

- 実図面差替データ（oj_eval）への推論: 旧JIS接点（○○＋斜め刃）を contact_a/b として検出することを目視確認（従来はすべて connector 誤認）。
- 公開参考図（ブログの新旧JIS比較図）: シンボル一覧表形式のため本評価対象外。

## 7. 判断事項・未決

- 旧JIS実図面のアノテーションデータが無いため、旧JIS評価は合成差替データによる代理評価。実図面の提供があれば実測に置き換える。
- `other` の一部を lamp/PB/diode に置き換えたことで、実図面の `other` 検出にわずかな回帰が出る可能性（回帰評価で確認）。
