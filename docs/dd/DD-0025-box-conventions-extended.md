# DD-0025: 記号の枠の取り決めを広げる（コネクタの目盛り線・ゆるい枠・カードの接点）

- 状態: レビュー中
- 作成日: 2026-11-09
- 関連文書: [DD-0017-box-conventions.md](DD-0017-box-conventions.md), [DD-0024-detection-recall-trials.md](DD-0024-detection-recall-trials.md), [SPECIFICATION.md](../SPECIFICATION.md)

## 1. 目的

DD-0024 §2 で、交差検証（未学習の図面）の見落とし 41 本のうち、検出は正しいのに枠の付け方が正解と違い、照合（重なり 0.5 以上）で落ちる記号が 4〜6 個あった。DD-0017 の枠の取り決めを広げて正解データをそろえ、交差検証の再現率を上げる。

## 2. 正解データの多数派を数えた

| 記号 | 多数派 | そろっていなかったもの |
| --- | --- | --- |
| コネクタの目盛り線（黒丸の上下 8〜31 px にある 25〜90 px の横線） | 正解は上 154/157 個、下 201/228 個で枠に含める | 含めていなかった 30 個を画像で確かめ、確かに目盛り線だった 19 個（ER21275 の 6 個、ER21302 の 10 個、ER21283・ER21293・ER21297 など）。端子台 2AT の列の 9 個（線の位置が違う）と ER21266・ER21315 の TB3 の 2 個は対象外にした |
| 枠の上下左右の空白 | 正解の記号の枠は、インクの外側の余白が中央値 0〜8 px（a 接点 237 個は左右 4 px、上下 0 px） | ER21237 の 5 個（SYM-0001・0008・0010・0011・0012）は名前の下の空白まで含み、高さが 2 倍あった（例: SYM-0011 は y 673〜741、インクは 692〜715） |
| カードの中の接点 | DD-0017 のとおり、接点の印と名前を囲み、カードの外側の黒丸とその名前（NC1・NC2・NO・COM）は含めない | ER21236 の 3 個（SYM-0005・0006・0007）は、DD-0017 で付け直したときに左下の端子名（NC2・COM）まで残り、接点のインクの左に 26〜28 px の空白があった |

a 接点の枠の幅は 23〜92 px に切れ目なく散らばり、「名前を含める／含めない」の 2 つの流儀には分かれていなかった（名前の無い接点は狭い）。名前を含める取り決めは DD-0017 のまま変えない。

## 3. 変更

- 修正の一覧（27 件、すべて `rebox`）: `analysis/tools/gold_corrections/box_conventions_20261109.json`。
  - コネクタの目盛り線を含める 19 件、ER21237 のゆるい枠を詰める 5 件（インクの外側 3 px まで）、ER21236 のカードの接点の左端を詰める 3 件（接点のインクの左 4 px まで）。
  - 各件に修正前の枠（`was_bbox_px`）を書き、ZIP の枠が違えば止まる（DD-0017 の `rebox`）。修正前後の枠を全件画像で確かめた。
- 正解の ZIP 4 つ（`gold_{a,b}_{fixed,coil}_conv.zip`、DGX の `data/`）に当てた。a に 20 件、b に 7 件。2 回目はすべて「当て済み」。当てる前の ZIP は `*_conv_20261109.zip` として残した。
- 取り決めを [SPECIFICATION.md](../SPECIFICATION.md) の「記号の枠の取り決め」に足した。
- コードは変えていない。同梱モデルも変えていない（§4）。

## 4. 測定

配線の処理は main（DD-0023）と同じ。予測は今の同梱の組み合わせ（30 枚モデル: `runs/ins_hyb_c50k60`、交差検証: `runs/e24hyb_c50k60`）。

| 指標 | 前の正解・30 枚モデル | 直した正解・30 枚モデル | 前の正解・交差検証 | 直した正解・交差検証 |
| --- | --- | --- | --- | --- |
| つながりの再現率（調整用 / 報告用 / 30 枚） | 0.982 / 0.991 / 0.9865 | 0.982 / 0.979 / 0.9806 | 0.975 / 0.977 / 0.9759 | 0.977 / 0.979 / **0.9782** |
| 見落とした配線（本） | 23 | 33 | 41 | **37** |
| 配線の電気的な正しさ | 0.9982 | 0.9982 | 0.9965 | 0.9965 |
| シミュレーションの一致 / 誤った励磁 | 0.871 / 29 | 0.871 / 29 | 0.843 / 32 | 0.843 / 32 |

- 交差検証では ER21237（2 → 0 本）と ER21275（2 → 0 本）の見落としが消えた。枠の照合で落ちるコネクタは 0 個になった。
- 30 枚モデルでは ER21237 の見落としが 0 → 10 本になった。30 枚モデルは ER21237 を学習に含み、前のゆるい枠をそのまま覚えて出すため。交差検証（ER21237 を学習に含まない分割）では逆に 2 → 0 本に減っており、枠を詰めたこと自体は正しい。

直した正解で学習し直した場合も測った（学習の条件は DD-0023 と同じ e24_conv_s7、カードは前の検出のまま）。

| 指標 | 直した正解・今の検出 | 直した正解・学習し直した検出 |
| --- | --- | --- |
| 30 枚モデルの再現率 / 見落とし | 0.9806 / 33 | **0.9865 / 23**（`runs/all_main_box`） |
| 30 枚モデルのシミュレーションの一致 / 誤った励磁 | **0.871** / 29 | 0.846 / **26** |
| 交差検証の再現率 / 見落とし | **0.9782 / 37** | 0.9764 / 40（`runs/e27_box_s7`） |
| 交差検証の記号の検出 F1 | 0.9855 | **0.9872** |
| 交差検証のシミュレーションの一致 / 誤った励磁 | **0.843 / 32** | 0.845 / 39 |

- 学習し直すと、30 枚モデルの再現率は前の値（0.9865）に戻るが、シミュレーションの一致が下がった。下がった ER21298 では、76 個の検出の位置は同じで、枠の縁が数 px 動いただけ（コイルの高さ 0.0643 → 0.066 など）だった。学習のゆれによるもので、枠の取り決めの効果ではない。
- 未学習の図面（交差検証）では、学習し直しても再現率は上がらず（37 → 40 本、ER21302 で 6 → 8 本）、誤った励磁が増えた。
- 実際に使うのは未学習の図面なので、同梱モデルは置き換えない。30 枚モデルの指標は、次に同梱モデルを学習し直すときに 0.9865 に戻る。

## 5. 98% に届かない分

交差検証の見落とし 37 本。98%（33 本以下）まであと 4 本。枠の照合で落ちる記号は a 接点 3 個（ER21236 の 2 個、ER21246 の 1 個）だけになり、どれも配線の見落としにはつながっていない。残りは本当に検出できていない記号（コネクタ 5、a 接点 4、b 接点 5、分岐の黒丸 8、母線 1、その他 1）と、両端の記号は対応しているのに端子・配線が欠けるもの。枠の付け方で取れる分は取り切った。DD-0024 §5 のとおり、次は正解付けした図面を増やす。
