# DD-0030: 行先札・来先札（シート間参照）で図面をまたいで配線をつなぐ

- 状態: レビュー中
- 作成日: 2026-11-18
- 関連文書: [DD-0029-circuit-code-whatif-impact.md](DD-0029-circuit-code-whatif-impact.md), [DD-0009-circuit-simulation.md](DD-0009-circuit-simulation.md), [DD-0007-accuracy-improvement-real-drawings.md](DD-0007-accuracy-improvement-real-drawings.md)（§4.6 その他の区分、§4.9 シート間参照）

## 1. 目的

これまで回路が図面をまたいでつながるのは、母線（PER/NER）と同じ器具番号のリレー（コイルと接点）だけだった。
行先札「ER21212へ」で別の図面へ続く配線は途切れたままで、別の図面にある機器への影響を「もしも」や波及範囲で
追えなかった（DD-0029 §7 の 2）。行先札と来先札を組にして、図面をまたいで同じノードにする。

## 2. 札の見分け方

| 札 | 条件 |
|----|------|
| 記号の札 | クラス「その他」で、ラベルにシート番号がある（`(ER21212)`、`ER21212へ`、`ER21212より`、`ER21212`。枝番 `-3` も可）。構造解析の取り込みはこの札のラベルを `ER21212へ` にする（`symbol_label`） |
| 札にしないもの | 盤・カード・端子台・遮断器の名前を含むラベル（`classify_other` と同じ正規表現）。接点・コイルの枠の中のシート番号（コイルのあるシート）はクラスが違うので対象外 |
| 配線の札 | 種別「シート間参照」の配線で、`external_ref` にシート番号があるもの。配線の終点を札とする。終点が記号の札なら、`external_ref` の語をその札の識別に足す |

札の記号は分岐点と同じく端子をすべて 1 つの点として扱う。種別「シート間参照」の配線は、これまで回路から除いていたが、
図面上の線なので導線としてもつなぐ。

## 3. 組にする規則

1. 札 t（図面 A、行先 B）と札 u（図面 B、行先 A）が向かい合うときだけ候補にする。シート番号は枝番を除いて比べる。
   図面のシート番号は図面情報の「シート番号」、空なら図面名の中のシート番号。
2. 札の識別 = ラベルのシート番号以外の語 ＋ 札につながる配線の電線番号 ＋ `external_ref` の語。両方に識別があれば
   共通の語があるときだけ候補（強い候補）。どちらかに無ければ弱い候補。
3. t の最良の候補が u だけで、u の最良の候補も t だけなら組にする。強い候補の組は「確認済み（matched）」、
   弱い候補の組は「推定（guessed）」として、確認が必要な箇所にも出す。
4. 組にならない札は確認が必要な箇所に理由を出す: 行先の図面が選ばれていない／向かう札が無い／候補が複数で決まらない／
   この図面のシート番号が分からない。

1 枚の図面から同じ行先へ複数の札が出るとき（例: ER21212 へ 610 番と 611 番）は、電線番号やラベルの語で区別できる
場合だけつなぐ。区別できないものは誤ってつながないことを優先する（波及範囲を誤って広げないため）。

## 4. 実装

| 追加・変更 | 内容 |
|------------|------|
| `services/sheet_links.py` | 札の判定（`sheet_tag_target`）、図面のシート番号（`page_sheet`）、札の組み合わせ（`link_tags`） |
| `services/circuit_model.py` | `build_circuit` で札を通り抜けの点にし、組にした札のノードを 1 つにする。`Circuit.sheet_links` に組を残す |
| `POST /api/circuit/build`・`/simulate` | `sheet_links`（組、確からしさ、両端の図面名と札）を返す |
| 回路シミュレーション画面 | 「図面間のつながり」の一覧（エディタの札へ移れる。推定には印） |

回路コード・もしも・波及範囲（DD-0029）は、つないだ後の回路を使うので、そのまま図面をまたいで追える。

## 5. テスト（`tests/test_sheet_links.py`）

- 行先札だけの図面では先が途切れ、両方の図面を選ぶと押しボタン（図面 A）でコイル（図面 B）が動く。
- 同じ行先へ 2 つの札があっても、電線番号で正しい相手につなぐ（並び順を逆にしても）。
- 区別できない 2 対の札はつながず、4 つとも確認が必要な箇所に出る。
- 選ばれていない図面への札、向かう札の無い札は理由つきで残る。
- 種別「シート間参照」の配線（`external_ref: "ER21212へ 610"`）でもつながる。
- 波及範囲と回路コードの書き出し・読み戻しが図面をまたいで成り立つ。API で `sheet_links` が返る。

## 6. 残っていること

- 実図面での確認: 札のラベルの書き方（電線番号が札の中にあるか、来先側の書式）は正解データの図面で確かめて規則を足す。
- コネクタの端子名（CN229 の 5 番など）による図面間の接続は未対応（同じコネクタ名と端子名を組にする規則が要る）。
- 札の行先の行列（`ER21011-3` の `-3`）は今は比べていない。同じ行先へ札が多い図面で区別に使えるか確かめる。
