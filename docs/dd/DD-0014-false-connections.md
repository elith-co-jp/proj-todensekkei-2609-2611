# DD-0014: つながっていない線をつなぐ誤りを減らす

- 状態: レビュー中
- 作成日: 2026-11-08
- 関連文書: [DD-0013-wiring-overhang.md](DD-0013-wiring-overhang.md)

## 1. 背景

移した正解の 30 枚で、取り込んだ配線のうち電気的に誤ったもの（つながっていない線をつないだもの）が 87 本あった（配線の正しさ 0.948）。誤りの多い図面（ER21276・ER21277・ER21279）を、配線のグラフで誤ったつながりの経路をたどって原因を確かめた。

## 2. 原因と変更

| 原因（図面） | 変更 |
| --- | --- |
| 間隔の狭い平行線（11 px おき）では、直交する配線の帯が隙間なく続く。はみ出しを縮める規則（DD-0013）が越えた帯を「帯に入った回数」で数えていたので 1 本と数え、曲がり角を越えて伸びた縦線を縮めていなかった（ER21276・ER21279） | 越えた帯を本数で数える（`detect._crossed_bands_before_ink`） |
| 「5 ○ (ER21271)」のように端子番号・端子の丸・参照先が横一列に並んだ行や、「2B-RCVTB(01)」の札の文字を横線として検出し、3 つの接点の下側の端子をつないでいた（ER21276 など 8 本） | 線に沿ったインクが 100 px あたり 10 回以上途切れる候補は文字の並びとして配線にしない（`detect.looks_like_text_row`）。30 枚の配線で、文字の並びは 10.0〜15.0 回、配線は端子の小箱が乗るものでも 8.7 回まで |
| 縦線が曲がり角で横線になって終わる点から、線の途切れの橋渡しが 11 px 下の別の横線へ掛かっていた（ER21277・ER21276） | 直交する配線もそこで終わる点（角）からは橋渡ししない（`connectivity` の `is_corner`） |
| 黒丸の無い交差を T 字とみなす判定で、交点から線に直角な向きに 8 px まで離れた配線の端を「この交点で終わる線」と数えていた。11 px おきの平行線では隣の線の端が入り、交差をつないでいた（ER21276・ER21279） | 直角な向きの許容を 3 px にする（`TEE_ACROSS_PX`）。線の向きの許容は 8 px のまま（`TEE_ALONG_PX`） |
| 母線の黒丸から 90 px 下の縦線へ端子からの橋渡しが掛かり、間にある接点を飛ばして黒丸とコネクタをつないでいた。接点は線が薄く端子を決められず、端子で見る既存の判定（`passes_device_terminal`）に現れなかった（ER21302） | 端子が 2 個に満たない接点・コイルの枠を、端子からの橋渡しがまるごと越えるときは掛けない（`passes_unported_device`）。枠は検出した記号から取る |
| 縦線がカードを上から下まで貫き、カードの端子が上の + しか見つからなかった。線がカードを素通りして + 側が下のコネクタにつながっていた（ER21303・ER21326） | カードを貫く線に端子が 1 個しかなければ、枠の中心で折り返した位置にもう 1 個置く（`ports.card_ports_across`）。接点で 1 端子のとき折り返すのと同じ考え |

## 3. 測定（移した正解、調整用 / 報告用 / 30 枚）

| 指標 | 変更前 | 変更後 |
| --- | --- | --- |
| 誤った配線（本） | 34 / 53 / 87 | 24 / 10 / **34** |
| 配線の電気的な正しさ | 0.957 / 0.941 / 0.948 | 0.969 / 0.988 / **0.979** |
| つながりの再現率 | 0.914 / 0.946 / 0.930 | 0.911 / 0.950 / 0.931 |
| シミュレーションに使えるコイル | 0.968 / 1.000 / 0.981 | 同じ |
| 以前の正解（再現率・正しさ、30 枚） | 0.921・0.969 | 0.922・0.982 |
| 誤って励磁した件数（AI のラベルのまま、30 枚） | 133 | **113** |
| 励磁の正しさ・再現（同） | 0.607・0.515 | 0.636・0.495 |

規則ごとの効果（30 枚の誤った配線）: 帯の数え方 87 → 71、文字の並び 71 → 56、角 56 → 46、T 字の判定 46 → 39（ER21276 6 → 2、ER21279 4 → 1）、端子の無い接点 39 → 37（ER21302 2 → 0）、カードの折り返し 37 → 34（ER21303 2 → 0、ER21326 1 → 0。ER21303 の取りこぼし 2 本も戻り、報告用の再現率が 0.948 → 0.950）。後の 3 つで再現率が下がった図面は無い。

再現率は調整用で 0.914 → 0.911（ER21302 で 1 本、ER21277 で 1 本）。ER21277 の 1 本は、黒丸の点で縦線が終わりそこから横線が始まる描き方で、角の規則が正しい橋渡しも止めたもの。

試して採用しなかったもの: 記号の検出の後処理（黒丸の無い分岐点・重なった同じ枠・2 つ目の図面全体の枠を捨てる）。誤った配線は減らず、ER21298 で 1 本増えた。

## 4. 残り

誤った配線の残り 34 本は ER21277（7）・ER21275（6）・ER21282（4）・ER21301（4）・ER21315（4）が多い。

- カードの中の接点（端子 4 個のカード接点）の付近: ER21275・ER21298・ER21301 の右側。うち数本は評価側で 4 端子の接点の端子を正解の端子に当てる仕方によるもので、検出の誤りとは限らない。
- ER21282・ER21283: 端子台のラベル行が横線として残る（文字の並びの判定の閾値より途切れが少ない）。
- ER21301 の左側の 2 本: カードの右の縁から 3 px 外を通る縦線に、カードの端子が付く。同じ形（カードの縁のすぐ外を通る線に端子が付く）は 30 枚で 14 か所あり、ほかの 12 か所はカードの上を通る母線への正しいつながりなので、位置の条件だけでは区別できず手を入れていない。

## 5. ロールバック

本 DD の差分を revert する。規則ごとに止めるときは `TEXT_ROW_GAPS_PER_100PX` を大きくする、`is_corner` の判定を外す、`TEE_ACROSS_PX` を 8 に戻す、`passes_unported_device` の呼び出しを外す、`card_ports_across` の呼び出しを外す。
