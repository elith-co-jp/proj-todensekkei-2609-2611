# DD-0045: 展開接続図から論理図を作り、論理図でシミュレーションする

- 状態: レビュー中
- 作成日: 2026-11-25
- 関連文書: [DD-0035](DD-0035-reading-procedure.md)（逆引き）, [DD-0033](DD-0033-timers-and-reading-errors.md)（タイマー）, [DD-0030](DD-0030-sheet-links.md), [DD-0009](DD-0009-circuit-simulation.md)

## 1. 目的

2026-11-25 に東電設計様から受け取った紙芝居（図面の読み方、7 ページ）は、展開接続図 EV31031〜EV31036（22号 LNG高圧ポンプ IBD）を
起動指令 6X の接点から逆に辿る手順（使用先のシート → リレー表との照合 → コイル → 接点を動かす元）を示し、最終ページで
それを論理図（ロジック図）にまとめている。本 DD は、図面の読み取り結果（アノテーション → 回路）から、この最終ページの図を
機械で作り、その図の上でシミュレーションする。

## 2. 論理図の作り方（`services/logic_diagram.py`）

1. 出力（既定は接点が M/C・他盤・表示灯へ出ていく最後のリレー。画面で選べる）のコイルから、DD-0035 の逆引きで成立条件を求める。
   直列 AND、並列 OR、b 接点 NOT。
2. 条件に出てくるリレーを同じ手順で繰り返し辿り、外部入力・参照先欠落・未解決で止める。
3. まとめる（`merge=False` で無効にできる）。
   - 条件が a 接点 1 つだけのリレー（83D ← D009、83DX ← 83D、6D ← D001）は元の信号の別名にする。
   - 同じ条件のリレー（83DX と 83DX-1、83M と 83M-1、20MB → 86T）は 1 つの信号にする。
   - 接点を通らず母線に直接つながるコイル（80 電源正常）は「電源」の入力（初期値 ON）にする。
4. タイマー（コイルの属性 timer_mode・delay_s）は遅延、キープリレーは S/R にする。
5. 何か所でも使う信号・タイマー・キープリレー・自己保持の信号にコネクタの英字（A, B, …）を付け、定義と参照を分ける。
   1 か所でしか使わないリレーは使う側の図に描き込む。英字は依存の浅い順、同じ深さは出力から辿って先に出る順。

### キープリレー（新規）

コイルの属性 `latch_coil`（set / O / セット、reset / R / リセット）で、同じ器具番号のどちらのコイルかを決める（`latch_priority=set`
でセット優先、既定はリセット優先）。回路の計算（`circuit_model.simulate`）・逆引きの 3 値の判定・回路コードも対応した。

### 母線 PEV / NEV（新規）

東電設計様の図面の母線「PEV110500」「NEV110500」を PER / NER と同じく電源の正・負にする。

### 名前

記号の属性 `signal_name`（コイル優先）か API の `names` で、紙芝居と同じ名前（主制御装置選択 など）を出す。
入力の別名のリレーに名前があれば、コネクタはその名前（入力は「主制御装置選択指令」、コネクタ A は「主制御装置選択」）。

## 3. 図（SVG）

紙芝居の書き方: AND は縦棒と小さい四角、OR は縦棒と小さい丸、NOT は線上の ⊠、外部入力は六角形（参照先欠落・未解決は点線）、
タイマーは D の形と時間、キープリレーは S/R の箱、出力は箱。すべて反転して入る AND は ¬(A ∨ B) の形で描く。
状態を与えると、成立している線・入力・出力をピンクにする。

## 4. シミュレーション

論理（信号）で解く。時刻つきの操作で入力を変え、タイマーの満了・キープリレーを含めて落ち着くまで解き、状態の変わった時刻ごとの
記録とタイムチャート用の波形を返す。`compare_with_circuit` は同じ操作を回路の計算（DD-0033 の run_timeline）でも解き、
リレーごとに照合する（論理図にする過程の誤りの検出）。

## 5. API と画面

| API | 内容 |
|---|---|
| `POST /api/circuit/logic` | 論理図（信号・ブロック・式・SVG・出力の候補）。inputs か values で線の色 |
| `POST /api/circuit/logic/simulate` | 時刻つきの操作。compare=true で回路の計算と照合 |
| `POST /api/circuit/logic/svg` | SVG のダウンロード |

回路検証の画面に「論理図」タブ: 図（大きく表示・SVG 出力・式で見る）、出力の選択、入力の ON/OFF、時間の流れ（記録を押すと
その時刻の状態で図を描き直す・タイムチャート・回路の計算との照合）。

## 6. 検証

紙芝居の図面を `analysis/synthetic_circuits/kamishibai.py` でアノテーションの形に再現し（器具番号・a/b・シート・増設リレー・
タイマー・キープリレーは原図どおり）、`tests/test_logic_diagram.py` で次を確かめた。

- 論理図が最終ページと同じ論理: A = 主制御装置選択、B = ¬A ∧ 定検保守装置 CPU 正常、C = 引ロック（S/R）、D = 1sec(¬(A ∨ B))、
  起動 = ((A ∧ 起動指令 個別) ∨ (B ∧ 起動指令 定検)) ∧ ¬C、停止 = (A ∧ 停止 個別) ∨ (B ∧ 停止 定検) ∨ C ∨ D ∨ ¬電源正常。
- 一連の操作（選択なしのトリップ・起動・引きロックと保持・解除・定検保守装置への切り替え・CPU 異常）の動きと、回路の計算との一致。
- シート EV31033 を抜くと、83M-1・86T が「参照先欠落」の入力（点線）になること。

## 7. 残り

- 実図面（スキャン）での読み取りから通すこと。PDF の I/O カード（D001 など）を外部入力と見分ける規則（今は属性 external_io）。
- 図の並び（AND の入力の順）は式の整理の順で、原図の上下の順とは限らない。
