# DD-0024: 未学習の図面の記号の検出漏れを減らす試験（交差検証の再現率 98% に向けて）

- 状態: レビュー中
- 作成日: 2026-11-09
- 関連文書: [DD-0023-dotted-bus-and-simulation.md](DD-0023-dotted-bus-and-simulation.md), [DD-0018-detail-scan-and-cards.md](DD-0018-detail-scan-and-cards.md)

## 1. 目的

DD-0023 の後、交差検証（未学習の図面）のつながりの再現率は 0.9759（見落とし 41 本）。98% には 33 本以下が要る。見落としのうち記号の検出に関わるものを減らす。

## 2. 見落とし 41 本の内訳（数え直し）

DD-0023 §5 では「25 本は片方の端の記号が検出されていない」と書いたが、これは「片方の端に AI の端子が対応しない」数で、記号はあるのに端子や配線が欠けるものを含んでいた。評価と同じ枠の照合（holdout_cv.match、重なり 0.5 以上）で数え直した。

| 内訳 | 本数 |
| --- | --- |
| 片方の端の記号が、枠の照合で正解と対応しない | 21 本（記号 11 個） |
| 両端の記号は対応している（端子・配線が欠ける） | 20 本 |

対応しない記号 11 個を、確信度 0.05 まで下げた予測で確かめた。

| 状態 | 記号 |
| --- | --- |
| 検出されているが、枠の付け方が正解と違い、重なりが 0.43〜0.49 で照合の基準 0.5 に届かない | ER21237 CN57 24、ER21275 CN79 7・9、ER21246 の接点（確信度 0.72〜0.92） |
| 確信度が下限（0.50、コネクタ 0.60）より低い | ER21226 の接点 33la（0.40）・母線（0.29）、ER21281 のコネクタ 52（0.41）、ER21302 の分岐の黒丸（0.39） |
| 候補がほとんど出ない・種類の取り違え | ER21297 の分岐の黒丸（0.05）、ER21298 の b 接点（a 接点と検出）、ER21266 の接点 AY13E（0.50 だが枠が違う）、ER21281 のコネクタ 50 |

## 3. 試したこと（どれも採用しない）

| 方法 | 結果 |
| --- | --- |
| 種類ごとの確信度の下限を、調整用の 15 枚で選ぶ | どの種類も今の下限が最良だった。下限を下げた改善（コネクタ・母線）は報告用の図面にだけ出る |
| テスト時の拡張（反転して予測し合わせる、TTA） | 誤検出が 19 → 335 個。図面の記号は左右・上下が非対称で、反転は合わない |
| 同じ条件で種の違う 2 つの yolo11s の検出を合わせる | 調整用 15 枚で見落とし 16 → 16 本（変化なし）、報告用 13 → 10 本。一般化する改善ではない |
| yolo11m（大きなモデル）で同じ条件で学習し直す（5 分割、約 2 時間） | 記号の見落とし 29 → 32、F1 0.9855 → 0.9846。学習データ 30 枚では大きなモデルの利点が出ない |
| 画像の塗りつぶした円から分岐の黒丸を足す | 30 枚の正解で分岐の黒丸 318 個のうち 271 個を見分けられたが、見落としていた黒丸（ER21297 は塗りの判定に届かず、ER21302 は線が薄く分岐に見えない）には当たらず、配線の指標は変わらなかった |

## 4. わかったこと

- 未学習の図面で本当に検出できていない記号は 7 個前後で、残りは枠の付け方の違い（検出は正しい）。
- 推論の工夫（確信度・TTA・組み合わせ）とモデルの大きさでは、未学習の図面の検出は良くならない。改善には学習データを増やすことが要る（同じ書き方の図面を正解付けして足す。とくにカードの中の接点、端子台の行のコネクタ、薄い母線の分岐の黒丸）。
- 配線の処理で直せる「両端の記号は対応している」見落とし 20 本も、盤の枠の中の白丸の間（試験用の端子とみられる）や、ほとんど消えた点線など、図面から読み取れない所が多い。

## 5. 次の候補

1. 正解付けした図面を増やす（30 枚 → 60 枚など）。交差検証の 98% にいちばん効くと考える。
2. 枠の付け方をさらにそろえる（DD-0017 の取り決めを、コネクタの下の短い横線・接点の名前の欄に広げる）。検出は正しいのに照合で落ちている 4 個が対象。
3. 薄い線・点線の多い図面は、DD-0018 の 300 dpi の読み込みを母線の行にだけ使う。

## 6. 変更

コードは変えていない（試験の記録）。試験の予測は DGX の `runs/e24_low05`・`runs/e24_tta05`・`runs/e26_m_s7` にある。
