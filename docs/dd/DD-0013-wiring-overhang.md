# DD-0013: 配線の正しさの改善（曲がり角を越えて伸びた線を縮める）

- 状態: レビュー中
- 作成日: 2026-11-08
- 関連文書: [DD-0009-circuit-simulation.md](DD-0009-circuit-simulation.md), [DD-0012-speed-and-ci.md](DD-0012-speed-and-ci.md)

## 1. 背景

配線の目標は 95%（つながりの再現率・配線の電気的な正しさ）。開始時（DD-0012 の状態）は移した正解の 30 枚で再現率 0.930・正しさ 0.930 だった。誤った配線 121 本のうち 89 本が ER21277・ER21276・ER21279・ER21275 の 4 枚に集まっていた。手掛かりは調整用（tune）の図面で探し、報告用（report）で確かめた。

## 2. 原因と変更

ER21277（tune）の図面下部では、CN79 の 4 本の縦線がそれぞれ曲がり角で左へ折れ、11〜12 px おきの 4 本の横線になって CN20 の列へ行く。配線のグラフをたどると、x=782 と x=864 の縦線が曲がり角（y=695・706）の先、下の横線（y=718）まで検出されていた。伸びた先の端が下の横線と T 字につながったとみなされ、4 本の横線が 1 つになっていた。縦線は下の横線を横切るインクを自分のインクとみなして伸びていた。

- `detect.trim_overhangs`: 配線の端から内側へたどり、直交する配線の帯（太さ ± 2 px）を除いて最初に自分のインクのある所まで、帯を 2 本以上・8 px より長く越えていれば縮める。母線や曲がり角に着く正しい端は着いた先の線を 1 本越えるだけなので縮めない。帯と帯の間に 10 px を超える隙間があれば、記号（接点など）で線が途切れているところなので縮めない。インクは配線の枠の幅で見る（ER21277 の軸 782 に対しインクは 784〜786）。
- `connectivity.dotted_junction_nodes`: 黒丸の付く交点を、黒丸から 24 px 以内の最も近い交点 1 つだけにした。調べた中で 24 px 以内の別の交差をつなぐ例があったが、測った値は変わらなかった（同じ交点が T 字の判定でもつながっていた）。2 か所にあった判定を 1 つにまとめた。

試して採用しなかったもの:

- 帯を 1 本越えるだけでも縮める版: 母線に T 字で着く縦線や曲がり角の横線も 10〜15 px 縮み、再現率が 0.930 → 0.892（隙間の上限なし）、0.926（隙間の上限あり）に下がった。

## 3. 測定（移した正解、調整用 / 報告用 / 30 枚）

| 指標 | 変更前 | 変更後 |
| --- | --- | --- |
| 配線の電気的な正しさ | 0.917 / 0.941 / 0.930 | **0.957** / 0.941 / **0.948** |
| つながりの再現率 | 0.914 / 0.946 / 0.930 | 0.914 / 0.946 / 0.930 |
| シミュレーションに使えるコイル（短絡） | 0.968 / 1.000 / 0.981（0） | 同じ |
| 以前の正解（再現率・正しさ、30 枚） | 0.921・0.970 | 0.921・0.969 |
| 誤って励磁した件数（AI のラベルのまま） | 95 / 68 / 163 | **65** / 68 / **133** |
| 励磁の正しさ（AI のラベルのまま） | 0.572 / 0.541 / 0.560 | **0.658** / 0.541 / **0.607** |
| 励磁の再現（AI のラベルのまま） | 0.580 / 0.447 / 0.520 | 0.571 / 0.447 / 0.515 |

縮めた配線は 30 枚で 5 本（ER21275・ER21277 の各 2 本、ER21280 の 1 本）。報告用の図面には当たらず、報告用の値は変わらない。

## 4. 残り（95% に届いていない理由）

再現率は調整用で 0.914（見落とし 71 本）。調整用の見落としを分けると次のとおりで、多くは配線の処理より前の段の問題。

| 原因 | 本数（目安） | 例 |
| --- | --- | --- |
| スキャンで線がほぼ消えている（画素の中央値が白） | 約 19 | ER21261 の母線から下りる点線、ER21302 の左 3 列の下側 |
| 線の片方の端に記号・端子が無い（記号の取りこぼし、母線の端） | 約 18 | ER21261 の 63LL の接点 |
| 検出した記号の枠が正解の枠と大きさが違い、記号が対応しない | 数本 | ER21236 のコネクタ（予測 75×50 px） |
| 図面下部の交差の束の残り | 数本 | ER21275 |

正しさの残り（調整用 34 本）は ER21277（11）・ER21302（6）・ER21275（6）。

## 5. ロールバック

本 DD の差分を revert する。縮める処理だけを止めるときは `analysis/wiring/detect.py` の `OVERHANG_TRIM_PX` を大きくする。
