# DD-0041: 図面セットで、図面をまたいだ回路・波及範囲・追跡を同じ組で回す

- 状態: レビュー中
- 作成日: 2026-11-21
- 関連文書: [DD-0009](DD-0009-circuit-simulation.md)、[DD-0030](DD-0030-sheet-links.md)、[DD-0035](DD-0035-reading-procedure.md)

## 1. 目的

回路・もしも・波及範囲・逆引き/順引きの API は、もともと図面の ID の並び（`project_ids`）で動き、複数の図面を選べば
母線・行先札・器具番号で図面をつなぐ（DD-0030）。ただし次の点が弱かった。

- 「どの図面を一緒に選べば一続きの回路になるか」を毎回人が選び直す。選び漏れると、行先札の先が切れたまま解く
  （確認が必要な箇所に「行先の図面が選ばれていない」と出るだけ）。
- 組を残せないので、同じ組で回路・波及範囲・追跡を繰り返し確かめにくい。

## 2. 変えたこと

- DB: `drawing_sets`（名前は一意）と `drawing_set_members`（セット × 図面）。1 枚の図面は複数のセットに入れてよい
  （電源の図面など、いくつかのセットが共有する図面がある）。図面を消すとセットからも外れる（外部キーの連鎖）。
  新しい表だけなので、既存の DB は起動時の `create_all` で表が足される（列の追加・移行は無い）。
  ロールバックは表を消すだけで、ほかの表には影響しない。
- `services/drawing_sets.py`・`routers/drawing_sets.py`（`/api/drawing-sets`）:
  - 一覧・作成・変更・削除。
  - 過不足（`/{id}/coverage`）: セットの図面の行先札と種別「シート間参照」の配線（`sheet_links.page_references`）が
    指すシートのうち、セットに無いもの。登録済みの図面にそのシートがあれば追加の候補を付ける。シート番号の分からない
    図面も出す（札をつなげないため）。シート番号は枝番を除いて比べる（DD-0030 と同じ）。
  - 組の候補（`/suggest`）: 登録済みの全図面を、行先札の向き先でつながるまとまり（連結成分）に分ける。保存はしない。
- 回路の API は変えない。画面はセットの `project_ids` をそのまま渡す。これで回路・もしも・タイマー・波及範囲・
  逆引き/順引き・整合性チェック・変更（DD-0034）のすべてがセット単位で動く。
- 画面（回路検証の図面選択）: 「図面セット」の選択、選択の保存（名前を付ける）・更新、「行先札から候補」、
  セットの過不足の表示と「登録済みの N 枚を選択に追加」。

## 3. 確認

| 対象 | 方法 | 結果 |
|---|---|---|
| 作成・変更・削除 | pytest（`tests/test_drawing_sets.py`） | 同じ名前は 400、無い図面は 404、図面を消すとセットから外れる、セットを消しても図面は残る |
| 過不足 | 送り側の図面だけのセット | 受け側のシート（ER21212）が足りないと出て、登録済みの図面が候補に付く。両方入れると `complete` |
| セット単位の回路 | 両方入れたセットの `project_ids` で simulate | 送り側の押しボタンで受け側のリレーが励磁する |
| 組の候補 | 札でつながる 2 枚と、未登録のシートを指す 1 枚 | 2 つのまとまりに分かれ、後者は `missing_sheets` に未登録のシート |
| 画面 | vitest（`DrawingSetBar.test.tsx`） | セットを選ぶと図面を選ぶ、足りない図面の追加、保存、候補 |

## 4. 残り

- 図面の改訂（同じシート番号の新旧）をセットの中で扱う方法は、改訂の差分（B2）と合わせて決める。
- シナリオファイル（DD-0035）の `drawing_set` は今は表の出力の列にだけ使う。セットの名前で図面を選ぶようにするのは次の段。
