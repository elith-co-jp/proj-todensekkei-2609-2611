# DD-0054: 傾き・かすれ・途切れのある強いスキャンで、配線の読み取りを上げる

- 状態: レビュー中
- 作成日: 2026-11-27
- 関連文書: [DD-0038](DD-0038-eval-suite.md)（評価）・[DD-0053](DD-0053-scan-frame-and-lamp-ports.md)（スキャンの枠と表示灯の端子）・[DD-0023](DD-0023-dotted-bus-and-simulation.md)（接点の棒の側）

## 1. 背景

DD-0053 の後、合成図面のスキャン風の劣化（線の太さ・粗さ・ぼけ・ノイズ）では配線の読み取りの誤りが出なくなった。
受領図面のスキャンには、ほかに傾き・かすれ（場所によって薄い）・線の途切れ・ごみ・白くない紙の地がある。
これを足した強い劣化（`analysis/synthetic_circuits/scan.py` の `scan_hard_variant`）で測ると、配線の再現率 92.4%、
回路が正解と一致する図面は 40 枚中 13 枚（32.5%）だった。

| 項目 | 値 |
|---|---|
| 傾き | ±0.3 度（1755 px の母線の両端で約 9 px） |
| かすれ | インクの濃さに 0.45〜1 を掛ける（4×6 の格子をなめらかに広げた面） |
| 線の途切れ | インクの上に半径 1〜3 px の白い円を 100 万画素あたり 60 個 |
| ごみ | 半径 0〜1 px の点を 100 万画素あたり 400 個 |
| 紙の地 | 232〜250 |

評価（`eval_suite.py --only drawings`）に `drawings.scan_hard.*` として足した。

## 2. 原因と決定

外れた図面を 1 枚ずつ見て、多い順に直した。

| 原因 | 直し方 | ファイル |
|---|---|---|
| 太った引き出し線と白丸の縁を「左の棒」とみなし、a 接点を b 接点に直していた | 線の幅（最も強い列の半分以上の列）の中心を線の列にし、線の中と、線から外へ弱まっていく肩は棒としない | `analysis/wiring/contact_kind.py` |
| かすれた線（灰色 190〜220）が、端子の候補の点のインク（180 未満）にならない | 点の周りに 180 未満の画素が無く、周りの地より 40 以上暗い画素があれば、地と最も暗い画素の中間を閾値にする。濃い線のある所は今までと同じ | `analysis/wiring/ports.py` の `point_ink_ratio` |
| 枠の外の線が 4〜7 px ずつ途切れ、線から端子を決める方法（`line_ports`）が線を見つけない | 今までの方法と薄い線の探し方で見つからないときだけ、途切れ 8 px まで許し、枠の外に 24 px 以上続く線を使う | `ports.py` の `line_ports`、`params.py` |
| 枠の高さ 65 px 以上の接点（4 端子とみなす）は、推定の端子が 1 つも付かなくても線から探さなかった | 端子が 1 つも無ければ線から 2 端子を探す | `analysis/wiring/linking.py` |
| 表示灯の丸の中は × の交点のほかは白く、推定の端子が付かない | 接点と同じく、貫く配線の上の枠の上下の辺を端子にする | `ports.py`（`LAMP_EDGE_FALLBACK`） |
| かすれで 1 本の線が 10〜20 px 途切れ、検出で 2 本の配線になり、上下が別の回路になった | 一直線（軸のずれ 3 px 以内）に向き合う 2 本の配線の端の間が 30 px 以下で、間に記号の枠が無ければつなぐ | `analysis/wiring/connectivity.py` の `add_collinear_bridges`、`params.py` |
| 傾きで、離れた黒丸どうしの上下がずれる | 黒丸どうしのずれの許しに、間の長さの 0.005 倍（約 0.3 度）を足す | `analysis/wiring/faint_lines.py` |
| ごみ・途切れで黒丸の形が崩れ、黒丸の中心が線から 3〜4 px ずれる | ずれが大きいときは、黒丸の外 8〜28 px で線が通る位置で測り直す | `faint_lines.py` の `_line_across` |

どれも、今までの方法で端子・線が見つからないときか、今までの閾値に届かない薄い所でだけ働くようにし、
きれいな図面と DD-0053 までのスキャン風の図面の結果は変えない。

## 3. 結果

調整は `eval_suite.py` の 40 枚（seed 2609、劣化 seed 1000〜）で行い、使っていない 120 枚（seed 31337、劣化 seed 5000〜）で確かめた。
記号は正解の位置を使う（YOLO の検出は含まない）。詳細は [evidence/DD-0054-hard-scan-20261127.md](../evidence/DD-0054-hard-scan-20261127.md)。

| 図面 | 指標 | 前 | 後 |
|---|---|---:|---:|
| 調整に使った 40 枚（強い劣化） | 配線の再現率 / 適合率 | 92.4% / 97.7% | 99.7% / 99.3% |
| | 回路が正解と一致 | 32.5% | 92.5% |
| 使っていない 120 枚（強い劣化） | 配線の再現率 / 適合率 | 93.4% / 97.6% | 98.8% / 99.0% |
| | 回路が正解と一致 | 41.7% | 75.8% |
| 使っていない 120 枚（きれい・従来のスキャン風） | すべて | 100% | 100% |

調整に使った図面と使っていない図面で回路の一致に差がある（92.5% と 75.8%）。使っていない図面で残る誤りの多くは、
表示灯・コイルの端子と下の母線の間、接点の端子の付き方で、次に直す候補。

## 4. 残り

- 受領図面（DGX の正解 30 枚）で、各ルールが働いた所と結果が変わらないかを `eval_reading.py` で確かめる。
- 傾きがもっと大きい図面（1 度以上）は、解析の前に傾きを直す方がよい。
