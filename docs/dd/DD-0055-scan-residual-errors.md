# DD-0055: 強いスキャンで残った誤りを種類ごとに数えて直す

- 状態: レビュー中
- 作成日: 2026-11-27
- 関連文書: [DD-0054](DD-0054-hard-scan-reading.md)（強いスキャンの劣化）・[DD-0038](DD-0038-eval-suite.md)（評価）

## 1. 背景と測り方

DD-0054 の後も、強いスキャンの劣化（傾き・かすれ・途切れ・ごみ・紙の地）では、調整に使っていない図面で回路が正解と
一致するのは 75.8% だった。調整に使った 40 枚（92.5%）との差は、40 枚に合わせすぎたためと考えた。

そこで図面の組を分け直した。

| 組 | 図面 | 使い方 |
|---|---|---|
| 調整用 | 120 枚（seed 31337、劣化 seed 5000〜。DD-0054 の確認用） | 誤りを数えて直す |
| 確認用 | 新しい 200 枚（seed 777、劣化 seed 9000〜） | 直した後に 1 回だけ測る |

誤りは、見落とした・余分な接続の両端の記号の種類と、その記号に付いた端子の数で数えた（解析の作業用スクリプト）。

## 2. 原因と決定（調整用 120 枚で多い順）

| 原因 | 回路が一致した図面の増減 | 直し方 | ファイル |
|---|---:|---|---|
| 電磁弁の四角の上下の辺が短い横線の配線として残り、電磁弁を貫く縦線の上に黒丸の無い交点を作って、電磁弁の両端子を短絡させた | +9（75.8%→83.3%） | コイル・電磁弁・表示灯の枠の中に収まる線は、その記号を直交する配線が端から端まで貫くときだけ記号の絵として外す（貫く線が無い記号の中の線は今までどおり残す） | `analysis/wiring/filter_wire_decorations.py` |
| 枠の高さ 65 px 以上の接点（4 端子の型）で、インクの途切れで 4 点の一部だけに端子が付き、内側の点が端子になって枠の上下の端子から離れた | +7（→89.2%） | 4 点がそろわなければ線から 2 端子を探し、見つかれば置き換える | `analysis/wiring/linking.py` |
| 黄ばみ・裏写りで紙の地が 232〜250 だと、薄い線の閾値（灰色 240・245）で紙全体が薄い線になり、コイルの端子が線の無い列に付いた | 下の 2 つと合わせて ±0（直る図面と崩れる図面が同じ数） | 薄い線を見るときだけ、紙の地（灰色の 90 パーセンタイル）が 250 未満なら地が 255 になるように伸ばす | `analysis/wiring/faint_lines.py` の `paper_gray`、`linking.py` |
| 傾いた図面で、コイルの下の端子と下の母線の黒丸が 4 px ずれた | 上と合わせて ±0 | 黒丸につながる線は、両端のすぐ外の線の位置で測り直し、間の長さ × 0.005 のずれを許す（DD-0054 の黒丸どうしと同じ） | `faint_lines.py` |

下の 2 つは調整用の回路の一致を変えなかったが、配線の再現率を上げ（99.1%→99.5%）、地が白くない紙・傾いた図面で
働く理由がはっきりしているので入れた。ほかに、画像全体の地を白くしてから解析する方法も試した。調整用 120 枚で回路の一致が 1.7 ポイント下がった（88.3% と 90.0%）
ので採らず、薄い線を見るときだけ伸ばした。

## 3. 結果

記号は正解の位置を使う（YOLO の検出は含まない）。詳細は [evidence/DD-0055-scan-residual-20261127.md](../evidence/DD-0055-scan-residual-20261127.md)。

| 図面 | 指標 | 前（DD-0054） | 後 |
|---|---|---:|---:|
| 調整用 120 枚（強い劣化） | 配線の再現率 / 適合率 | 98.8% / 99.0% | 99.5% / 99.6% |
| | 回路が正解と一致 | 75.8% | 89.2% |
| **確認用 200 枚（強い劣化）** | 配線の再現率 / 適合率 | 98.9% / 98.8% | 99.5% / 99.5% |
| | 回路が正解と一致 | 74.0% | 88.0% |
| 確認用 200 枚（きれい・従来のスキャン風） | すべて | 100% | 100% |
| 評価スイート 40 枚（強い劣化） | 回路が正解と一致 | 92.5% | 95.0% |

調整用と確認用の差は 1.2 ポイントで、DD-0054 のときの 16.7 ポイントから縮んだ。

## 4. 残り

- 確認用で残る誤りの多くは、線の途切れが多すぎる（線の 1 割以上が白い）下の母線への線と、母線の黒丸どうし。
  線がこれ以上途切れた図面は、受領図面で実際にどのくらいあるかを見てから扱う。
- 受領図面（DGX の正解 30 枚）で結果が変わらないかを確かめる。
