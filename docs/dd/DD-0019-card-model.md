# DD-0019: カードを別のモデルで検出する組み合わせをアプリに入れる

- 状態: レビュー中
- 作成日: 2026-11-08
- 関連文書: [DD-0018-detail-scan-and-cards.md](DD-0018-detail-scan-and-cards.md), [DD-0017-box-conventions.md](DD-0017-box-conventions.md), [SPECIFICATION.md](../SPECIFICATION.md)

## 1. 決めたこと

DD-0018 §3 の組み合わせ（カードは前の正解で学習した検出、ほかの記号は枠の取り決めをそろえた正解で学習し直した検出）をアプリに入れる（2026-11-08 にチャットで決定）。

## 2. 変更

- **モデル**: 30 枚すべてと b 接点の追加 16 ページで、交差検証と同じ設定（yolo11s、1280 px、150 エポック、90°・270° に回した複製）で 2 つ学習した。
  - `assets/models/yolo11s_symbols_best.pt`（ほかの記号用）: そろえた正解、種 7。sha256 `2fa535cd…bf683`。
  - `assets/models/yolo11s_cards_best.pt`（カード用）: そろえる前の正解、種 2609。sha256 `5b8f5846…193c5`。
  - これまでの同梱モデル `yolo11n_all_symbols_best.pt`（yolo11n）は外した。
- **推論**（`services/inference_service.py`）: 使用中のモデルで全記号を検出し、カード用のモデルがあれば「その他」（カード・札・領域）だけをその検出に置き換える（`merge_card_detections`）。結果のモデル名は「使用中のモデル + yolo11s_cards_best」。
- **カード用のモデルの場所**（`services/model_service.card_model_path`）: exe では同梱の `models/`、開発時は `assets/models/`。環境変数 `SEQANNO_CARD_MODEL` で差し替え、空で使わない。DB は変えていない（モデル一覧・採用の対象は今までどおり使用中のモデル 1 つ。アプリで学習し直すのもほかの記号用のモデル）。
- **画面**: AI 改善サイクルの「解析を実行する」に「カードは別モデル（yolo11s_cards_best）」を表示（`GET /api/ml/status` の `card_model`）。
- **EXE**: 2 つのモデルを同梱（`seq-annotator.spec`）。ビルド後の確認（`scripts/smoke_packaged_ml.py`）で、初期モデルの登録とカード用のモデルの表示を確かめる。

## 3. 測定

### 3.1 30 枚すべてで学習したモデル（学習に使った 30 枚で採点）

学習に使った図面で採点しているので、未学習の図面より高く出る。これまでの同梱モデルとの比較の目安。

| 指標（そろえた正解、配線の処理は main） | これまでの同梱モデル（yolo11n） | 組み合わせ（30 枚で学習） |
| --- | --- | --- |
| 記号の検出 F1 | 0.9521（誤検出 37・見落とし 124） | **0.9959**（4・10） |
| つながりの再現率 | 0.891（見落とし 183） | **0.964**（61） |
| 配線の電気的な正しさ | **0.983**（誤り 29） | 0.976（誤り 41） |
| シミュレーションに使えるコイル | 0.792 | **0.981** |
| シミュレーションの一致 / 誤った励磁 | 0.678 / 96 | 0.706 / 123 |

記号を多く見つけるほど配線の処理がつなぐ所も増え、誤りは 29 → 41 本（ER21282 +4、ER21281 +3 など図面に分散）、誤った励磁は 96 → 123 件（ER21298・ER21315・ER21297 で、つながったコイルが増えた）になった。

### 3.2 未学習の図面（5 分割の交差検証、DD-0018 §3）

| 指標 | 組み合わせ |
| --- | --- |
| つながりの再現率 | 0.9565 |
| 配線の電気的な正しさ | 0.9805 |
| シミュレーションの一致 / 誤った励磁 | 0.713 / 52 |

これまでの同梱モデルは交差検証の設定（yolo11s）とは別に学習したもので、同じ条件の交差検証の値は無い。

### 3.3 アプリでの動作

開発環境のアプリ（一時 DB）に ER21315 を取り込み、解析を実行した。カード用のモデルがあるとき、結果のモデル名は「yolo11s_symbols_best + yolo11s_cards_best」、状態の `card_model` は `yolo11s_cards_best`、並んだ 4 枚のカードは別々の枠になった。`SEQANNO_CARD_MODEL` を空にすると使用中のモデルだけで検出した。

## 4. 残り

- 30 枚で学習したモデルの採点では、配線の正しさが 98% を下回る（0.976）。記号の検出が良くなって配線の処理がつなぐ所が増えたためで、配線の処理の側（DD-0014・DD-0016 の誤りの規則）で詰める。
- つながりの再現率 98% は、未学習の図面で 0.9565（DD-0018 §4 の残り）。

## 5. ロールバック

`SEQANNO_CARD_MODEL` を空にすればカード用のモデルを使わない。モデルを戻すには、アプリの AI 改善サイクル画面で以前のモデルを使用中にするか、本 DD の差分を revert して EXE を作り直す。
