# DD-0052: 登録したデータを画面から削除する

- 状態: レビュー中
- 作成日: 2026-11-27
- 関連文書: [DD-0039](DD-0039-analysis-jobs.md)（裏の解析ジョブ）、[DD-0041](DD-0041-drawing-sets.md)（図面セット）、[DD-0047](DD-0047-explicit-state-machines.md)（状態の移り方）

## 1. 背景と決定

2026-11-27 に利用者から「登録しているデータを削除できるようにしてほしい」と依頼があった。登録されるデータを洗い出すと、
図面とモデルは消せたが、確認が「取り消せません」の一言かブラウザの確認だけで、何が一緒に消えるか分からなかった。
解析結果・学習の履歴・回路の変更履歴・図面セットは画面から消せず、I/O 表は確認なしで外れた。また図面を消しても
画像ファイルが残り、その図面を含む回路の変更履歴は（図面が無いので）元に戻そうとすると失敗する状態で残っていた。

次のとおり決めた。

- 消す前に必ず確認を出し、**一緒に消えるもの**と**残るもの**を件数つきで並べる（共通の `ConfirmDeleteDialog`）。
- **実行中のジョブが使っているデータは消さない**（途中で消すとジョブが失敗し、結果が半端に残るため）。確認の中に理由を出し、削除ボタンを押せなくする。API は 409 を返す。
- 状態は変えない。`services/lifecycles.py` の状態（学習中・解析中）を読むだけにする。

## 2. データごとの扱い

| データ | 消す場所 | 一緒に消えるもの | 残るもの | 消せないとき |
| --- | --- | --- | --- | --- |
| 図面 | 図面一覧で選んで「削除」→「図面ごと削除」 | アノテーション（記号・端子・配線）、AI の検出候補、構造解析の結果、図面セットへの所属、ベクター PDF の線、その図面を含む回路の変更履歴、ほかの図面が使っていない画像ファイルと縮小画像 | 学習の履歴（図面の ID だけ無効になる）、モデル、I/O 表、書き出し済みの ZIP | 裏の解析・学習が使っている |
| AI の解析結果 | 図面一覧で選んで「削除」→「AI の解析結果だけ削除」 | AI の検出候補、構造解析の結果（エディタの確認状況の集計も出なくなる） | 図面・画像、アノテーション（AI から取り込んだものも含む）、図面セット、履歴 | 裏の解析が使っている（学習は始めた時に書き出すので妨げない） |
| モデル | AI 学習 → モデル管理 | モデルの登録、ほかの登録が使っていなければファイル | 検出候補・構造解析の結果、学習の履歴（できたモデルの欄が空になる） | 使用中のモデルで解析中、学習の起点に使っている |
| 学習の履歴 | AI 学習 → 学習履歴 | 学習の記録（評価・ログ）、作業フォルダ `data/training/run_<id>` | できたモデル、学習に使った図面 | 学習中 |
| 回路の変更履歴 | 回路検証 → 図面の変更 → 履歴 | 変更の記録（変更前の図面を含む。適用中なら元に戻せなくなる） | 今の図面 | なし |
| 図面セット | 回路検証 → 図面セット | セットの名前・メモ・組み合わせ | 図面とアノテーション | なし |
| I/O 表 | デモ → 「I/O 表を外す」 | 登録した表（次に回路を組んだときから外部入力の印と信号名が付かない） | 図面とアノテーション | なし |

対象外: 記号の種類（クラス）は記号・候補が参照し、取り決め（`symbol_class_policy.py`）で決まるので消せないままにする。
裏の解析ジョブの一覧はプロセスの中だけにあり、再起動で消えるので消す操作は作らない。表の読み取り（PR #107）は図面に付くので、図面と一緒に消える。

## 3. API

- `POST /api/projects/delete-preview` `{ids}`: 確認に出す件数（`counts`）と消せない理由（`blockers`、解析結果だけを消すときは `analysis_blockers`）。何も消さない。
- `DELETE /api/projects/{id}`・`POST /api/projects/bulk-delete`: 上の規則で消す。実行中なら 409。
- `POST /api/ml/analysis/clear` `{ids}`: 検出候補と構造解析の結果だけを消す。
- `DELETE /api/ml/training/runs/{id}`: 学習中は 409。
- `DELETE /api/ml/models/{id}`: 使用中のモデルで解析中、または学習の起点なら 409。
- `DELETE /api/circuit/edit/{id}`: 変更の履歴を 1 件消す。

実装は `services/data_deletion.py`、試験は `tests/test_data_deletion.py`（消えるもの・残るもの・共有の画像・実行中の扱い）と画面の各テスト。
