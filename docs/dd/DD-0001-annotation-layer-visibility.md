# DD-0001: アノテーションのレイヤー表示切替

- 状態: レビュー中
- 作成日: 2026-10-10
- 関連文書: [SPECIFICATION.md](../SPECIFICATION.md)

## 1. 背景

AI 推論結果をアノテーションエディタで確認・修正する際、bbox が重なり合うとクリックが常に最前面の矩形に当たり、下にある編集したい枠を直接選択・移動・リサイズできない。現状はクラス単位で対象を隠す手段がなく、座標の直接編集や削除→再登録で回避するしかない。

## 2. 目的

- アノテーションの種類ごとに表示 ON/OFF を切り替え、重なった bbox の下にある対象へマウスで直接到達できるようにする。
- 表示切替はあくまで画面上の見え方と当たり判定の制御であり、アノテーションデータ自体は変更しない。

## 3. スコープ

- 対象: アノテーションエディタ画面（`/projects/:id`、EditorPage）。
- スコープ外: 解析結果画面（`/projects/:id/analysis`。既にシンボル／配線の表示切替と配線濃度調整があり、閲覧専用のため今回は変更しない）、保存・エクスポート・推論 API、Undo/Redo の対象範囲。

## 4. 変更案の概要

図面キャンバス右上に「レイヤー」パネルを常駐させ（ツールバーの「レイヤー」ボタンで開閉）、アノテーションの種類ごとに目アイコンで表示を切り替える。

1. **レイヤーの構成**
   - 配線（connections 全体）
   - 端子（全シンボルの terminals 全体）
   - AI 検出（`origin === 'inference'` のシンボル全体）
   - シンボル（種別）: クラスマスタの並び順で、図面内に存在するクラスごとに1行
2. **表示状態の持ち方**: 非表示シンボルを ref の集合（`hiddenSymbols`）として保持する。クラス行や AI 検出行の目アイコンは、そのグループに属するシンボルの非表示フラグを一括で立てる／下ろす操作。クラス行は「全部表示」「全部非表示」「一部非表示（一部のみクリックで全て表示）」の3状態を表示する。
3. **個別の非表示**: 詳細パネルのシンボル一覧の各行に目アイコンを追加し、1枠だけ隠せるようにする（同じクラス同士が重なったケースに対応）。非表示行は半透明表示し、行をクリックすると再表示して選択する。
4. **非表示の影響範囲**: 非表示シンボルは描画しないほか、`hitSymbol` / `hitTerminal` / `hitCorner` の当たり判定からも除外する。これによりクリックが下のレイヤーの枠へ届く。端子レイヤーを OFF にすると端子へのヒットは行わずシンボル本体を選ぶ（配線はシンボル単位で登録される）。配線レイヤーの OFF は描画のみを止め、一覧上の配線データは維持する。
5. **選択との整合**: 選択中のシンボルが非表示になったら選択を解除する（見えない枠を編集状態にしない）。配線モードの始点保留中シンボルが非表示になった場合も保留を解除する。シンボルを削除したらその非表示フラグも破棄する。
6. **モード連動**: 端子モードに入ったとき端子レイヤーが OFF なら ON に、配線モードに入ったとき配線レイヤーが OFF なら ON に戻す（置いた結果が見えない状態で作業させない）。
7. **ページ切替**: 図面を移動したら非表示シンボルの集合はリセットする（ref はページ間で再利用されるため）。端子・配線レイヤーの ON/OFF は作業傾向として維持する。
8. **新規追加との関係**: 非表示フラグは ref 単位なので、クラスの全枠を隠した後に描いた新規シンボルは表示される（描いたものが見える）。クラス行は「一部非表示」状態に見える。
9. **すべて表示**: パネル上端に「すべて表示」ボタンを置き、全レイヤーを一括で表示に戻せるようにする。

## 5. 検討した代替案

- **クラス単位の永続フラグ（ref ではなく class_key を保持）**: 同じクラス同士の重なりに対応できず、新規描画が即座に消える問題もあるため不採用。ref 集合＋グループ一括操作にした。
- **クリックで前面→背面へ順送り選択**: 何が選ばれるか予測しにくく、重なり枚数が多い図面では操作数が増えるため不採用。レイヤーで隠す方式の方が CAD ライクで直感的。
- **解析結果画面へのクラス別レイヤー追加**: 閲覧専用で編集不能のため、本件の課題（編集対象へ到達できない）とは独立。必要になれば別途検討する。
- **詳細パネルのタブにレイヤーを置く**: パネルを閉じると操作できなくなるため不採用。キャンバス上に常駐するパネル＋ツールバーボタンとした。

## 6. 影響・リスク

- 表示切替はクライアント側の画面状態のみで、保存ペイロード・エクスポート・Undo/Redo の履歴には含めない（データに影響しない）。
- ページ移動で非表示状態はリセットされる（ref 再利用による誤非表示を防ぐため）。意図的な仕様とする。
- 非表示シンボルを選択解除する実装により、隠した直後に Delete キーで誤削除するリスクを防ぐ。

## 7. 未決事項（人への判断）

- 非表示の単位を「クラス一括＋個別 ref」の2段とした設計（クラス単位の独立フラグは持たない）。
- AI 検出レイヤーは「origin が inference のシンボル全部」をまとめて隠す操作として提供する。手動登録シンボルだけをまとめて隠す行は設けない（クラス行と「すべて表示」で代替）。

## 8. 検証

- レイヤー OFF で対象シンボルが非表示になり、下に重なっていた枠がクリックで選択・移動・リサイズできることを実ブラウザで確認。
- クラス一括・個別・AI 検出・端子・配線・すべて表示の各操作、非表示中の選択解除、モード連動による自動再表示、ページ移動でのリセットを確認。
- 既存テスト全件に加え、非表示フィルタと当たり判定の単体テストを追加。ブラウザ console の error / warning が 0 件であること。
