# DD-0047: 論理図の注目点から辿り、図面の記載を確かめる

- 状態: レビュー中
- 作成日: 2026-11-26
- 関連文書: [DD-0046](DD-0046-drawing-logic-demo.md)（デモ画面）, [DD-0045](DD-0045-logic-diagram.md)（論理図）

## 1. 目的

デモ画面（DD-0046）で、論理図のどこに注目するかを決め、そこから原因（上流）・影響（下流）へ辿りながら、実際の図面にどう書かれて
いるかを確かめられるようにする。見たいことは人によって違うので、見方を複数用意して切り替えられるようにする。

## 2. つながり（`LogicDiagram.deps`）

- 信号 → その信号を決める信号（式の葉）。`negated` は NOT の数の偶奇で反転して効くか、`port` はキープリレーの S / R。
  `/api/circuit/demo` の `logic.deps` で返す（`/api/circuit/logic` の JSON にも入る）。
- SVG は論理図のまとまり（定義・出力ごとの 1 段）を `<g data-block="信号 ID">` で囲む。経路の外のまとまりを薄くするのに使う。

## 3. 辿り方（`frontend/src/pages/demo/trace.ts`）

- `traceFrom(deps, 注目点, 向き, 段数)`: 上流（deps）・下流（deps を逆向きにした「使う側」）へ、段数の浅い順に辿る。同じ信号は最初に着いたときだけ。
- `tourSteps`: 図面を 1 か所ずつ見る手順。上流の信号は、親のコイルと同じ図面にある接点（親の条件に入っている接点）を先に、
  その信号のコイル（その信号を決める回路）をあとに見る。原因だけを辿るときは注目点の接点（効く先）は出さない。

## 4. 見方（`frontend/src/pages/demo/FocusTrace.tsx`）

- 向き: 原因へ（上流）／影響へ（下流）／両方。段数: 1 段・2 段・すべて。
- 経路: 注目点からの木（反転は ¬、キープリレーは [S]/[R]、今の ON/OFF、図面の箇所数）。論理図は経路の外を薄くし、図面には経路に入る
  信号のコイル・接点すべてに枠を付ける。項目を押すとその信号のコイルへ移り、「注目点に」で注目点を移す。
- 順に辿る: 前へ・次へで図面を 1 か所ずつ拡大し、図面の切り抜きと「〇〇の a 接点。6X の条件に入る」のような説明を出す。図面の枠は今の 1 か所だけ。
- 一覧: 関係する箇所を図面の切り抜き（記号のまわり、CSS の背景で図面の画像を使う）と並べた表。行を押すとその箇所へ移る。

## 5. 試験

- `tests/test_logic_diagram.py`: 6X の上流に A・B・C（C は反転）と起動指令の入力、43LK に S/R、SVG のまとまりの数と g の対応。
- `frontend/src/pages/demo/trace.test.ts`: 上流・下流・段数・両方の順、手順の並び（親の図面の接点が先）。
- `frontend/src/pages/DemoPage.test.tsx`: 経路・順に辿る（向きで注目点の接点が入るか）・一覧（切り抜き）の切り替え。
