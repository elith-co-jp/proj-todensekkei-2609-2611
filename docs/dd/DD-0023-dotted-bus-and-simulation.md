# DD-0023: 上部の母線のまばらな点線をつなぎ、シミュレーションの一致を上げる

- 状態: レビュー中
- 作成日: 2026-11-09
- 関連文書: [DD-0022-inside-wires-and-recall.md](DD-0022-inside-wires-and-recall.md), [DD-0009-circuit-simulation.md](DD-0009-circuit-simulation.md)

## 1. 目的

- 交差検証（未学習の図面）でも、つながりの再現率 98% を目指す。最大の見落としのまとまりは、上部の母線の行のまばらな点線（DD-0022 §4）。
- シミュレーションの一致を上げ、誤った励磁を減らす。

## 2. 配線: まばらな点線

スキャンでほとんど消えた上部の母線の行の線は、灰色の点が 5〜30 px おきに残るだけで、薄い線の判定（灰色の割合 3 割以上、途切れ 24 px 以内）に届かなかった。正解でつながる点線では、薄い点が 100 px あたり 7〜29 個並び、最大の途切れは 33 px 以内。白い紙では点は 0 個だった。

- **点線の判定**（`faint_lines._dotted_line`）: 薄い点（濃さ 128 より明るい点。交わる配線の濃い点は数えない）が 3 個以上、100 px あたり 5 個以上あり、途切れが 35 px 以内の線を、薄い線と同じく端子どうしの間でつなぐ。
- **接点の端子**（`ports._dotted_column`）: 白丸しかなく端子を決められなかった接点（ER21261 の 63LL など）は、枠の上と下の外に同じ列で点が 2 個以上ずつ並ぶ列を端子にする。

## 3. シミュレーション

交差検証で、AI が読んだ器具番号をそのまま使うと一致は 0.702 だった。記号の名前だけ正解に差し替えると 0.895 になる。差の大部分は、正解のコイルと AI のコイルの名前が合わないこと（17 個 / 100 個）だった。

| 原因 | 変更 |
| --- | --- |
| コイルの丸の中の 2 桁の器具番号（43、30）と 1 文字の機器名（F）を、端子番号として落としていた（「43 3AM」→「3AM」） | コイルは枠の中心から高さ・幅の 1/4 以内の語を名前として残す（`text_extraction.COIL_NAME_BAND`）。端子番号は丸の上下の外にある |
| 接点の名前の 1 文字（「10ESD X」の X）を落とし、正解の入力と対応しなかった | 接点は枠の右半分の英字 1 文字を名前として残す（`_contact_name_letter`）。端子番号と線の読み違いは白丸の列（左寄り）にある |
| 同じ接点に a 接点と b 接点の枠が重なって検出され、閉じたままの b 接点で入力に関係なく励磁した（ER21299 の 43A3、ER21293 の 30CU） | 接点の棒の側で 1 つにする（`contact_kind.merge_contact_duplicates`）。この図面集では a 接点は白丸の右に棒、b 接点は左に棒がある。正解の接点 250 個で、棒の側は a 236 / b 12 と一致し、どちらとも言えないのは 2 個 |
| 未学習の図面で a・b を取り違えた接点（8 個） | 棒の側がはっきりしていれば種類を合わせる（`correct_contact_kinds`）。7 個が正しくなり、検出が正しい接点で棒の側が逆を示したものは無かった |
| 正解の分岐の黒丸に端子が無く、配線が回路から落ちていた（ER21297。正解のコイルが励磁しようがなく、AI の正しい励磁が誤りと数えられた） | 端子の無い通り抜けの点（分岐点・コネクタ）は記号そのものを 1 つの節点にする（`circuit_model.PASS_NODE_TERMINAL`）。アプリでも同じ登録が回路に入る |
| 器具番号の無い接点の入力名に記号の ref が入り、正解と AI で ref が違うため入力の On/Off が AI に伝わらなかった（ER21261） | 評価で、枠の対応で入力名を読み替える（`eval_circuit_sim.unlabeled_input_names`） |

## 4. 測定

枠の取り決めをそろえた正解（コイルの配線を含む）で採点した。「変更前」は main（DD-0022）。

### 4.1 30 枚で学習したモデル（学習に使った 30 枚で採点）

| 指標 | 変更前 | 本 DD |
| --- | --- | --- |
| つながりの再現率 | 0.9806（見落とし 33） | **0.9865（23）** |
| 　調整用 15 枚 / 報告用 15 枚 | 0.9701 / 0.9907 | 0.982 / 0.9907 |
| 配線の電気的な正しさ | 0.9982（誤り 3） | 0.9982（3） |
| シミュレーションの一致 | 0.757 | **0.871** |
| 正しく励磁したコイルの割合 / 励磁の正しさ | 0.602 / 0.922 | **0.767 / 0.935** |
| 誤った励磁 | 26 | 29 |

### 4.2 未学習の図面（5 分割の交差検証）

| 指標 | 変更前 | 本 DD |
| --- | --- | --- |
| つながりの再現率 | 0.9706（見落とし 50） | **0.9759（41）** |
| 　調整用 / 報告用 | 0.9641 / 0.9768 | 0.9749 / 0.9768 |
| 配線の電気的な正しさ | 0.9964（誤り 6） | 0.9965（6） |
| シミュレーションの一致 | 0.702 | **0.843** |
| 　調整用 / 報告用 | 0.737 / 0.652 | 0.895 / 0.768 |
| 正しく励磁したコイルの割合 / 励磁の正しさ | 0.472 / 0.896 | **0.708 / 0.923** |
| 誤った励磁 | 28 | 32 |
| 名前の合わないコイルの状態 | 327 | 116 |

正解で励磁するコイルの状態は 513 → 545 件に増えた（端子の無い黒丸を通る正解の配線が回路に入ったため）。誤った励磁は 30 枚モデルで 26 → 29、交差検証で 28 → 32 件と少し増えた。名前が合って比べられるコイルが増え、それまで比べられなかった誤りが表に出たためで、残りの多くは ER21299（14 件）と ER21294（5 件）。

## 5. 残り

- **交差検証の再現率は 0.9759 で 98% に届かなかった**（見落とし 41 本、98% には 33 本以下）。41 本のうち 25 本は、片方の端の記号が未学習の図面で検出されていない（ER21266 の接点 AY13E、ER21281 の端子台 50、ER21302 の母線の黒丸など）。30 枚モデルでは同じ種類の見落としは 9 本。配線の処理で直せる「両端の記号はある」見落としは 15 本で、すべて直しても上限は 0.985。98% には記号の検出の改善（学習データを増やす、未学習の図面の検出漏れを減らす）が要る。
- ER21299 の誤った励磁 14 件は、接点「3F1LU X」の「X」を文字の読み取り（OCR）が読んでおらず、正解の入力と対応しないため。
- ER21298 の盤の枠の中の 2 つの白丸の間（試験用の端子とみられる）は、接点と見分けがつかず、つないでいない。

## 6. ロールバック

- 点線: `DOTTED_MIN_DOTS` を大きくすれば使わない。接点の点線の列は `PortParams.dotted_min_dots` を大きくする。
- 名前: `COIL_NAME_CLASSES`・`CONTACT_NAME_CLASSES` を空にする。
- 接点の種類: `runtime.py` の `merge_contact_duplicates`・`correct_contact_kinds` を外す。
- 回路: `PASS_NODE_TERMINAL` の分岐を外すと、端子の無い点の配線は以前どおり回路に入らない。
- 全体は本 DD の差分を revert する。
