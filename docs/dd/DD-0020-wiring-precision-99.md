# DD-0020: つながっていない線をつなぐ規則を見直し、30 枚で学習したモデルでも配線の正しさを 99% 以上に戻す

- 状態: レビュー中
- 作成日: 2026-11-09
- 関連文書: [DD-0019-card-model.md](DD-0019-card-model.md), [DD-0016-missed-connections.md](DD-0016-missed-connections.md), [DD-0014-false-connections.md](DD-0014-false-connections.md)

## 1. 目的

DD-0019 で同梱した 30 枚で学習したモデル（カード用とほかの記号用の組み合わせ）では、記号を多く見つけるぶん配線の処理がつなぐ所も増え、配線の電気的な正しさが 0.976（誤り 41 本）に下がった。配線の処理の側の規則を見直し、99% 以上に戻す。再現率とシミュレーションに使えるコイルは下げない。

## 2. 誤り 41 本の原因

誤りごとに、正解の端子とつながった経路（どの規則でつないだか）を出し、図面の画像で確かめた。

| 原因 | 本数 | 例 |
| --- | --- | --- |
| コネクタ・カードの枠を**かすめる線**の上に端子ができた | 16 | ER21281・ER21282・ER21283 の端子台の行（枠の下の辺を飛び越しの横線が通る）、ER21301（カードの枠の右端を隣のコネクタの縦線が素通りする）、ER21298・ER21315 |
| 高さが 4〜8 px ずれた**黒丸どうし**を薄い線でつないだ | 7 | ER21276・ER21279・ER21280 の下部の交差の束（11 px おきの平行な横線を拾った）。うち 2 本はその黒丸を経由したコネクタどうし |
| 接点の中で終わる線の端から、**接点の下の端子を越えて**橋渡しした | 4 | ER21261・ER21276 の母線の黒丸から下りる 83D ESD |
| 交差の束で、交差の手前で切れた縦線から横線へ橋渡しした | 4 | ER21275・ER21277（CN20 8 の縦線が横線を越えて下の黒丸まで続く） |
| カードの中の接点の白丸の上にもカードの端子ができた | 2 | ER21276・ER21277 |
| 正解の登録と合わない（図面ではつながっている） | 6 | ER21277 の D014 は正解で接点の端子 1 と 2 を直接つないでいる。ER21226 は接点とカードの配線が正解に無い。ER21315 の 3 本はカードの列の上に端子が無く、カードの中の配線（同じ記号の端子どうし）でつないでいる |
| その他 | 2 | ER21261 のカードどうし、ER21282 の接点とコネクタ |

## 3. 変更（採用した 3 つの規則）

- **枠をかすめる線の端子を除く**（`ports.grazes_box_edge`、`PortParams.graze_edge_px = 3`）: コネクタとカードで、端子の線が枠の辺から 3 px 以内を辺と平行に走り、直交する辺から離れているとき、その端子は作らない。線が枠に入らず通り過ぎているだけだから。黒丸・接点の枠は線にぴったり沿うので対象外（辺の上の端子が普通）。
- **黒丸どうしの薄い線はそろったときだけ**（`faint_lines.JUNCTION_ALIGN`）: 分岐の黒丸は太い線の上に描かれ、薄い線で結ばれることはない。黒丸どうしは高さのずれが 3 px 以内（濃い線のときと同じ基準）のときだけ薄い線でつなぐ。この規則で外れた薄い線 5 本はすべて誤りで、正しくつないでいた黒丸どうしの薄い線は 1 本も外れていない。
- **接点をまたぐ橋渡しを止める**（`connectivity` の `own_device_jump_classes`）: コイルについてあった「機器の中で終わる線の端からの橋渡しが、同じ機器のもう一方の端子を越えない」規則（ER21298）を接点にも広げた。

試して採用しなかったもの:

- カードの端子のうち、接点の枠の中のもの（または接点の端子から 4 px 以内のもの）を除く案。誤りは数本減るが、カードの下の黒丸の端子も消える。枠の中で除く版は見落としが 61 → 162 本、4 px 以内の版でも交差検証で 72 → 101 本（再現率 0.957 → 0.940）に増えた。
- 交差の手前で切れた線からの橋渡しで、相手の線の向こうにも線が続けば交差とみなす案。ER21275・ER21277 には効かず、ER21302 で誤りが 2 本増えた。
- 黒丸の無い交差への端子の吸着を、交わる線のうち最も近い 1 本だけにする案（既存の `preferred`）。結果が変わらなかった。

## 4. 測定

枠の取り決めをそろえた正解（コイルの配線を含む）、配線の処理だけを変えて採点。正しさの分母は判定対象の配線（30 枚で約 1,680 本）。

### 4.1 30 枚で学習したモデル（学習に使った 30 枚で採点）

| 指標 | 変更前（main） | 変更後 |
| --- | --- | --- |
| 配線の電気的な正しさ | 0.976（誤り 41） | **0.9917（誤り 14）** |
| 　調整用 15 枚 / 報告用 15 枚 | 0.9752 / 0.9768 | 0.9849 / 0.9977 |
| つながりの再現率 | 0.9637（見落とし 61） | 0.9643（60） |
| 　調整用 / 報告用 | 0.9526 / 0.9744 | 0.9513 / 0.9767 |
| シミュレーションに使えるコイル | 0.981 | 0.981 |
| シミュレーションの一致 / 誤った励磁 | 0.706 / 123 | **0.727 / 78** |
| 正しく励磁したコイルの割合（on_recall） | 0.604 | 0.587 |
| 以前の正解での正しさ | 0.9818 | 0.9931 |

### 4.2 未学習の図面（5 分割の交差検証）

| 指標 | 変更前 | 変更後 |
| --- | --- | --- |
| 配線の電気的な正しさ | 0.9805（誤り 33） | 0.9892（誤り 18） |
| 　調整用 / 報告用 | 0.9786 / 0.9821 | 0.9797 / 0.9977 |
| つながりの再現率 | 0.9565（見落とし 73） | 0.9571（72） |
| シミュレーションの一致 / 誤った励磁 | 0.713 / 52 | 0.719 / 41 |

調整用・報告用のどちらでも正しさは上がり、再現率は調整用の 30 枚モデルで 0.001 下がった（ER21302 の見落とし 1 本）ほかは同じか上がった。シミュレーションで正しく励磁したコイルの割合が 0.604 → 0.587 に下がったのは、誤った配線を通って偶然励磁していたコイル 7 件が励磁しなくなったため。誤った励磁は 45 件減った。

## 5. 残り

- 30 枚モデルの残りの誤り 14 本のうち 6 本は、図面ではつながっているのに正解の登録と合わないもの（§2）。ER21277 の D014 の配線と ER21226 の接点とカードの配線（3 本）は正解の誤りとみられ、確かめて直せば正しさは 0.993 前後になる。ER21315 の 3 本は、カードの中の配線を評価でどう扱うかの取り決めの問題。
- 実際の誤りは 8 本で、うち 4 本は ER21275・ER21277 の交差の束で、検出が交差の手前で切れた縦線を T 字とみなして橋渡ししたもの。線の検出の側で交差を越えて線を続けるのが筋で、次の課題にする。
- 交差検証では 0.9892 で、99% まであと 2 本。

## 6. ロールバック

規則ごとに値で外せる: `PortParams.graze_edge_px = 0`、`faint_lines.JUNCTION_ALIGN` を `ALIGN` に、`own_device_jump_classes` を `classes.COILS` に。全体は本 DD の差分を revert する。
